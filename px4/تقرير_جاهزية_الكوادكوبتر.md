## 2) الخطوة الأولى: التحقق من خريطة الأوامر (`apps.cpp`)

**الملف:** `AndroidApp/app/src/main/cpp/apps.cpp`

**النتيجة:** خريطة الـ `apps` الخاصة ببناء Android **لا تحتوي على `rocket_gnc` إطلاقاً**. الوحدات المفعَّلة هي فقط الوحدات القياسية للكوادكوبتر + الجناح الثابت:

| وحدة | الحالة | الاستخدام |
|------|--------|-----------|
| `sensors`, `ekf2`, `commander`, `navigator` | ✅ | أساسية |
| `mavlink`, `logger`, `land_detector`, `dataman` | ✅ | أساسية |
| **`mc_att_control`, `mc_pos_control`, `mc_rate_control`** | ✅ | **متحكمات الكوادكوبتر** |

## 3) الخطوة الثانية: التحقق من `px4_jni.cpp` (بدء النظام)

**الملف:** `AndroidApp/app/src/main/cpp/px4_jni.cpp`

### 3.1 Airframe الافتراضي
- `SYS_AUTOSTART = 4001` → **`4001_quad_x` (Generic Quadcopter)** عند أول تشغيل.
- يتم الحفاظ على قيمة المستخدم إذا غيّرها لاحقاً من QGroundControl.

### 3.2 البارامترات المحورية للكوادكوبتر (تُضبط عند أول تشغيل أو تغيير الـ airframe)

| البارامتر | القيمة | المعنى |
|----------|--------|--------|
| `MAV_TYPE` | **2** | Quadcopter |
| `CA_ROTOR_COUNT` | **4** | أربع مراوح |
| `CA_ROTOR0..3_PX/PY/KM` | Quad‑X | الهندسة القياسية X |
| `SYS_HAS_GPS` | 0 | لا يوجد GPS خارجي |
| `EKF2_GPS_CTRL` | 0 | تعطيل دمج GPS |
| `EKF2_HGT_REF` | 0 | الارتفاع من الباروميتر |
| `EKF2_MAG_TYPE` | 6 (Init) / 5 (HITL) | البوصلة للتهيئة فقط |
| `COM_RC_IN_MODE` | 1 | Joystick عبر MAVLink (QGC Virtual Joystick) |
| `COM_ARM_WO_GPS` | 2 | السماح بالتسليح بدون GPS (تحذير فقط) |

### 3.3 تسلسل تشغيل الوحدات (Boot)
1. `load_mon` → مراقبة CPU/RAM (مطلوب من commander)
2. `sensors` → معالجة الحساسات
3. `ekf2` → تقدير الحالة
4. `commander` → مدير التسليح والأوضاع (مع `-h` لو HITL)
5. `dataman` + `navigator` → المهام والمسارات
6. `land_detector start multicopter` → ← **حرفياً كوادكوبتر**
7. `flight_mode_manager`, `manual_control`
8. **`mc_att_control`, `mc_pos_control`, `mc_rate_control`** (الكوادكوبتر)
9. `fw_att_control`, `fw_rate_control` (خاملة لأن `MAV_TYPE=2`)
10. `control_allocator` → يحوّل `vehicle_thrust_setpoint`/`vehicle_torque_setpoint` إلى `actuator_motors`
11. `arduino_output` → يأخذ `actuator_motors[0..3]` ويحوّلها إلى PWM (1000..2000 µs) ويرسلها للأردوينو
12. `gps_usb_ubx` (اختياري إذا اتُّصل GPS USB)
13. `mavlink` → UDP 14550 ↔ QGC

**الحكم:** تدفق التشغيل سليم 100% للطائرة الرباعية.

## 4) الخطوة الثالثة: درايفر `arduino_output`

**الملف:** `AndroidApp/app/src/main/cpp/arduino_output.cpp`

- يشترك في `actuator_motors` (الموضوع الجديد في PX4 v1.17+).
- يتعامل مع **4 قنوات** فقط (Quadcopter).
- يحوّل القيم `[-1, 1]` إلى PWM `[1000, 2000]` ميكروثانية:
  ```cpp
  pwm = 1500 + (motors.control[i] * 500)   // للاتجاهين
  // أو
  pwm = 1000 + (motors.control[i] * 1000)  // ESC أحادي الاتجاه
  ```
- يدعم `actuator_test` (من MAVLink Console).
- يدعم "disarmed" (NaN → PWM=1000 أو إطار 900 للإيقاف الفوري).
- يعمل عند 50 Hz.

**الحكم:** متوافق تماماً مع الكوادكوبتر.
