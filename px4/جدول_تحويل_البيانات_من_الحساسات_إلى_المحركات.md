# جدول تحويل البيانات: من الحساسات إلى المحركات

---

## 📋 مقدمة

هذا الجدول يتتبع **رحلة البيانات** من لحظة إدخال المستخدم (عبر التطبيق أو Joystick) حتى تصل إلى المحركات، مع توضيح **نوع البيانات**، **من يحولها**، **أين تُنشر**، و**من يستلمها**.

---

## 📊 الجدول الشامل

| # | البيانات | نوعها | تحولت إلى | من الذي حولها | نُشرت في | من الذي استلمها |
|---|----------|-------|-----------|---------------|---------|-----------------|
| 1 | **إحداثيات اللمس** على شاشة Android | `int` (بكسلات: x, y) | قيم تحكم موحدة | تطبيق Android (Joystick Logic) | - | نظام PX4 عبر USB |
| 2 | **قيم التحكم من Android** | `int` (MAVLink: 0-1000) | قيم معيارية (-1.0 إلى +1.0) | MavlinkReceiver في PX4 | `manual_control_setpoint` | Multicopter Controller |
| 3 | **manual_control_setpoint** | `float` (roll, pitch, yaw, thrust) | معدلات دوران مطلوبة (rad/s) | PID Controller (mc_att_control) | `vehicle_rates_setpoint` | Mixer Module |
| 4 | **vehicle_rates_setpoint** | `float` (roll_rate, pitch_rate, yaw_rate) | إشارات تحكم لكل محرك (-1.0 إلى +1.0) | Multirotor Mixer | `actuator_controls` | Actuator Outputs Module |
| 5 | **actuator_controls** | `float` (-1.0 إلى +1.0) | قيم PWM (μs) | Actuator Outputs Module | `actuator_outputs` | Android App (Subscription) |
| 6 | **actuator_outputs (PWM)** | `uint16_t` (900-2100 μs) | بايتات (Bytes) مع بروتوكول | تطبيق Android (Protocol Builder) | USB Serial Stream | Arduino (Serial Buffer) |
| 7 | **USB Serial Bytes** | `uint8_t[]` (بايتات خام) | قيم PWM مستخرجة | Arduino (executeCommand) | - | Servo Library |
| 8 | **PWM Values في Arduino** | `uint16_t` (900-2100) | إشارات كهربائية (Pulse Width) | Servo.writeMicroseconds() | Arduino Pin Output | ESC |
| 9 | **إشارة PWM إلى ESC** | `Pulse Width` (900-2100 μs) | سرعة محرك (%) | ESC (Internal Controller) | MOSFET Output | Motor |
| 10 | **سرعة المحرك** | `%` (نسبة مئوية) | دوران فعلي (RPM) | Motor (Brushless DC) | - | **الحركة الفعلية** |

## 🔍 تفصيل كل مرحلة

### المرحلة 1: إحداثيات اللمس → قيم تحكم

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `touchX = 320, touchY = 180` (بكسلات) |
| **النوع** | `int` (إحداثيات الشاشة) |
| **التحويل** | `offsetX = (touchX - centerX) / (screenWidth / 2)` |
| **النتيجة** | `roll = 0.0, pitch = 0.2, yaw = 0.0, thrust = 0.7` |
| **النوع الجديد** | `float` (-1.0 إلى +1.0) |
| **من الذي حول** | تطبيق Android (Joystick Logic) |
| **الموقع** | داخل تطبيق Android |

---

### المرحلة 2: قيم تحكم → manual_control_setpoint

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `roll = 0.0, pitch = 0.2, yaw = 0.0, thrust = 0.7` |
| **النوع** | `float` في تطبيق Android |
| **التحويل** | MAVLink Encoding + USB Serial |
| **النتيجة** | `manual_control_setpoint_s { x=0.2, y=0.0, z=0.7, r=0.0 }` |
| **النوع الجديد** | `uORB Topic: manual_control_setpoint_s` |
| **من الذي حول** | MavlinkReceiver في PX4 |
| **نُشرت في** | `manual_control_setpoint` topic |
| **استلمها** | Multicopter Controller |

---

### المرحلة 3: manual_control_setpoint → vehicle_rates_setpoint

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `manual_control_setpoint { x=0.2, z=0.7 }` |
| **النوع** | `manual_control_setpoint_s` |
| **التحويل** | PID Controller: `output = Kp×error + Ki×∫error + Kd×d(error)/dt` |
| **النتيجة** | `vehicle_rates_setpoint { roll=0.0, pitch=0.5, yaw=0.0, thrust=0.7 }` |
| **النوع الجديد** | `uORB Topic: vehicle_rates_setpoint_s` |
| **من الذي حول** | MulticopterAttitudeControl (PID) |
| **نُشرت في** | `vehicle_rates_setpoint` topic |
| **استلمها** | Mixer Module |

---

### المرحلة 4: vehicle_rates_setpoint → actuator_controls

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `vehicle_rates_setpoint { roll=0.0, pitch=0.5, yaw=0.0, thrust=0.7 }` |
| **النوع** | `vehicle_rates_setpoint_s` |
| **التحويل** | Mixer: `output[i] = thrust + roll×coef[i] + pitch×coef[i] + yaw×coef[i]` |
| **النتيجة** | `actuator_controls { output[0]=0.9, output[1]=0.9, output[2]=0.5, output[3]=0.5 }` |
| **النوع الجديد** | `float[]` (-1.0 إلى +1.0) |
| **من الذي حول** | Multirotor Mixer |
| **نُشرت في** | `actuator_controls` topic |
| **استلمها** | Actuator Outputs Module |

---

### المرحلة 5: actuator_controls → actuator_outputs

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `actuator_controls { output[0]=0.9, output[1]=0.9, output[2]=0.5, output[3]=0.5 }` |
| **النوع** | `float[]` (-1.0 إلى +1.0) |
| **التحويل** | `PWM = 1500 + (output × 500)` |
| **النتيجة** | `actuator_outputs { pwm[0]=1950, pwm[1]=1950, pwm[2]=1750, pwm[3]=1750 }` |
| **النوع الجديد** | `actuator_outputs_s { uint16_t pwm[MAX_ACTUATORS] }` |
| **من الذي حول** | Actuator Outputs Module |
| **نُشرت في** | `actuator_outputs` topic |
| **استلمها** | Android App (Subscription) |

---

### المرحلة 6: actuator_outputs → USB Serial Bytes

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `actuator_outputs { pwm[0]=1950, pwm[1]=1950, pwm[2]=1750, pwm[3]=1750 }` |
| **النوع** | `actuator_outputs_s` |
| **التحويل** | بروتوكول: `[0xAA][0x55][N][PWM_H][PWM_L]...[Checksum]` |
| **النتيجة** | `[AA][55][04][07][9E][07][9E][06][D6][06][D6][2A]` |
| **النوع الجديد** | `byte[]` (12 بايت) |
| **من الذي حول** | تطبيق Android (Protocol Builder) |
| **نُشرت في** | USB Serial Stream |
| **استلمها** | Arduino (Serial Buffer) |

---

### المرحلة 7: USB Serial Bytes → PWM Values في Arduino

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `[AA][55][04][07][9E][07][9E][06][D6][06][D6][2A]` |
| **النوع** | `uint8_t[]` (بايتات خام) |
| **التحويل** | `PWM = (HighByte << 8) | LowByte` |
| **النتيجة** | `pwm[0]=1950, pwm[1]=1950, pwm[2]=1750, pwm[3]=1750` |
| **النوع الجديد** | `uint16_t[]` |
| **من الذي حول** | Arduino (executeCommand) |
| **الموقع** | buffer[] في Arduino |
| **استلمها** | Servo Library |

---

### المرحلة 8: PWM Values → إشارات كهربائية

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `pwm[0]=1950, pwm[1]=1950, pwm[2]=1750, pwm[3]=1750` |
| **النوع** | `uint16_t` (قيم رقمية) |
| **التحويل** | `esc[i].writeMicroseconds(pwm)` → إشارة PWM كهربائية |
| **النتيجة** | إشارة كهربائية بعرض 1950μs على Pin 7 |
| **النوع الجديد** | `Pulse Width` (إشارة تناظرية) |
| **من الذي حول** | Servo Library + Arduino Hardware Timer |
| **الموقع** | Arduino Digital Pin Output |
| **استلمها** | ESC (Electronic Speed Controller) |

---

### المرحلة 9: إشارة PWM → سرعة محرك

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | إشارة PWM بعرض 1950μs |
| **النوع** | `Pulse Width` (900-2100 μs) |
| **التحويل** | ESC يقيس العرض → يحسب النسبة: `(PWM - 1000) / 1000 × 100%` |
| **النتيجة** | `Motor 0 Speed = 95%` |
| **النوع الجديد** | `%` (نسبة مئوية) |
| **من الذي حول** | ESC (Internal Microcontroller + MOSFETs) |
| **الموقع** | داخل ESC |
| **استلمها** | Motor (Brushless DC) |

---

### المرحلة 10: سرعة المحرك → حركة فعلية

| البند | التفاصيل |
|-------|----------|
| **البيانات الأصلية** | `Motor 0 = 95%, Motor 1 = 95%, Motor 2 = 75%, Motor 3 = 75%` |
| **النوع** | `%` (نسبة مئوية) |
| **التحويل** | فرق القوى بين المحركات → عزوم → حركة |
| **النتيجة** | الطائرة تميل للأمام وتتقدم |
| **النوع الجديد** | **حركة فعلية** (Pitch Forward) |
| **من الذي حول** | الفيزياء (القوى والعزوم) |
| **الموقع** | الطائرة (الهواء) |
| **استلمها** | **الطائرة تتحرك!** |

## 📈 ملخص سريع

| من نوع | إلى نوع | عدد المراحل |
|--------|---------|-------------|
| `int` (بكسلات) | `float` (قيم تحكم) | 1 |
| `float` | `uORB Topic` | 2 |
| `uORB Topic` | `float[]` (Mixer Output) | 3 |
| `float[]` | `uint16_t` (PWM) | 4 |
| `uint16_t` | `byte[]` (بروتوكول) | 5 |
| `byte[]` | `uint16_t` (Arduino) | 6 |
| `uint16_t` | `Pulse Width` (إشارة) | 7 |
| `Pulse Width` | `%` (سرعة) | 8 |
| `%` | **حركة فعلية** | 9 |

## ⚠️ ملاحظات هامة

1. **كل تحويل يحدث في وقت مختلف** - من اللمس إلى الحركة قد يستغرق 10-50ms.

2. **النظام يعمل بشكل مستمر** - يتم تحديث القيم مئات المرات في الثانية.

3. **كل مرحلة لها بنية بيانات مختلفة** - من `int` إلى `float` إلى `uint16_t` إلى `byte[]`.

4. **كل تحويل يحتاج تحقق** - Checksum، حدود أمان، قص قيم.
