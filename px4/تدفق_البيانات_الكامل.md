# تدفق البيانات الكامل — من QGC إلى المحركات

## المسار الكامل

```
QGroundControl (حاسوب)
    │
    │ MAVLink عبر راديو CP2102
    ▼
تطبيق Android (PX4 v1.17)
    │
    │ uORB: actuator_test / actuator_motors
    ▼
arduino_output.cpp (C++ driver)
    │
    │ إطار ثنائي 12 بايت
    ▼
px4_jni.cpp (JNI bridge)
    │
    │ Java ByteArray
    ▼
UsbDeviceManager.kt (Kotlin)
    │
    │ USB bulkTransfer
    ▼
Arduino Mega 2560 (ATmega16U2 → ATmega2560)
    │
    │ Servo PWM (1000-2000µs)
    ▼
ESCs → محركات
```

---

## الخطوة 1: إرسال الأمر من QGC

**المصدر:** QGroundControl على الحاسوب  
**الأمر:** `actuator_test set -m 1 -v 0.15`  
**البروتوكول:** MAVLink عبر راديو CP2102 (TCP:5760 → UDP:14550)

QGC يرسل رسالة MAVLink نوع `COMMAND_LONG` أو `ACTUATOR_TEST` إلى PX4 على الهاتف.

---

## الخطوة 2: PX4 ينشر على uORB

**الملف:** داخل PX4 (modules/commander أو mavlink receiver)  
**البيانات الداخلة:** رسالة MAVLink  
**البيانات الخارجة:** موضوع uORB `actuator_test`

PX4 يستقبل الأمر ويحوله إلى نشر uORB:
```c
actuator_test_s test;
test.action = ACTION_DO_CONTROL;   // = 0
test.function = FUNCTION_MOTOR1;   // = 1 (للمحرك الأول)
test.value = 0.15f;                // قيمة بين 0.0 و 1.0
```

---

## الخطوة 3: arduino_output.cpp يقرأ uORB

**الملف:** `AndroidApp/app/src/main/cpp/arduino_output.cpp`  
**الدالة:** `ArduinoOutput::Run()` — تعمل كل 20ms (50Hz)

### 3أ: قراءة actuator_test
```cpp
actuator_test_s test;
while (_test_sub.update(&test)) {
    if (test.action == actuator_test_s::ACTION_DO_CONTROL) {
        int motor_idx = (int)test.function - (int)actuator_test_s::FUNCTION_MOTOR1;
        // motor_idx = 0 للمحرك الأول
        _test_value[motor_idx] = test.value;  // = 0.15
    }
}
```

### 3ب: تحويل القيمة إلى PWM
```cpp
float v = _test_value[i];          // 0.15
if (v < 0.0f) v = 0.0f;
if (v > 1.0f) v = 1.0f;
pwm[i] = (uint16_t)(1000 + (v * 1000.0f));
// pwm[0] = 1000 + (0.15 × 1000) = 1150 ميكروثانية
```

**جدول التحويل:**
| قيمة الإدخال | PWM (µs) | المعنى |
|:---:|:---:|:---:|
| 0.0 | 1000 | متوقف |
| 0.15 | 1150 | بطيء |
| 0.50 | 1500 | متوسط |
| 1.0 | 2000 | أقصى سرعة |
| NaN | 900 | نزع التسليح |

## الخطوة 4: بناء الإطار الثنائي

**الملف:** `AndroidApp/app/src/main/cpp/arduino_output.cpp`  
**الدالة:** `ArduinoOutput::send_frame(const uint16_t pwm[4])`

### شكل الإطار (12 بايت):
```
بايت   القيمة          الوصف
─────────────────────────────────────────
[0]    0xAA            بايت المزامنة الأول
[1]    0x55            بايت المزامنة الثاني
[2]    0x04            عدد القنوات (4 محركات)
[3]    PWM0 >> 8       المحرك 0 — البايت العالي
[4]    PWM0 & 0xFF     المحرك 0 — البايت المنخفض
[5]    PWM1 >> 8       المحرك 1 — البايت العالي
[6]    PWM1 & 0xFF     المحرك 1 — البايت المنخفض
[7]    PWM2 >> 8       المحرك 2 — البايت العالي
[8]    PWM2 & 0xFF     المحرك 2 — البايت المنخفض
[9]    PWM3 >> 8       المحرك 3 — البايت العالي
[10]   PWM3 & 0xFF     المحرك 3 — البايت المنخفض
[11]   XOR             checksum (XOR لكل البايتات 0-10)
```

### مثال عملي:
`actuator_test set -m 1 -v 0.15` → المحرك 0 = 1150µs، الباقي = 900µs
```
[AA] [55] [04] [04][7E] [03][84] [03][84] [03][84] [checksum]
              motor0=1150  motor1=900  motor2=900  motor3=900
```

### الكود:
```cpp
frame[0] = 0xAA;  // PROTO_SYNC_H
frame[1] = 0x55;  // PROTO_SYNC_L
frame[2] = 4;     // num_channels

for (uint8_t i = 0; i < 4; i++) {
    frame[3 + i*2]     = (uint8_t)(pwm[i] >> 8);    // بايت عالي
    frame[3 + i*2 + 1] = (uint8_t)(pwm[i] & 0xFF);  // بايت منخفض
}

uint8_t checksum = 0;
for (size_t i = 0; i < 11; i++) checksum ^= frame[i];
frame[11] = checksum;
```

## الخطوة 5: إرسال عبر JNI (C++ → Java)

**الملف:** `AndroidApp/app/src/main/cpp/px4_jni.cpp`  
**الدالة:** `arduino_send_pwm_via_java_impl(const uint8_t* data, size_t len)`

```
C++ uint8_t[12]  ──JNI──▶  Java byte[12]
```

### ما يحصل:
1. يحصل على `JNIEnv*` (يربط thread C++ بـ Java VM)
2. يُنشئ `jbyteArray` بحجم 12
3. ينسخ البيانات: `env->SetByteArrayRegion(arr, 0, 12, data)`
4. يستدعي: `UsbDeviceManager.sendPwmDirect(arr)`
5. يُنظف المرجع ويفك ربط thread

```cpp
jbyteArray arr = env->NewByteArray((jsize)len);
env->SetByteArrayRegion(arr, 0, (jsize)len, (const jbyte*)data);

jmethodID mid = env->GetStaticMethodID(
    g_UsbDeviceMgrClass, "sendPwmDirect", "([B)I");
jint result = env->CallStaticIntMethod(g_UsbDeviceMgrClass, mid, arr);
```

`g_UsbDeviceMgrClass` يُحفظ عند تحميل المكتبة في `JNI_OnLoad()`.

## الخطوة 6: إرسال USB من Android

**الملف:** `AndroidApp/app/src/main/java/com/ardophone/px4v17/usb/UsbDeviceManager.kt`  
**الدالة:** `sendPwmDirect(data: ByteArray): Int`

### ما يحصل:
1. يجلب `sArduinoConn` (UsbDeviceConnection المحفوظ)
2. يبحث عن BULK OUT endpoint
3. يرسل: `conn.bulkTransfer(outEp, data, 12, 1000ms)`
4. إذا فشل → يعيد المحاولة مرة واحدة

```kotlin
var sent = conn.bulkTransfer(outEp, data, data.size, 1000)
if (sent < 0) {
    Thread.sleep(1)
    sent = conn.bulkTransfer(outEp, data, data.size, 1000)
}
```

**القيمة المرجعة:** عدد البايتات المرسلة (12 = نجاح، سالب = فشل)

## الخطوة 7: استقبال على Arduino

**الملف:** `PX4_Arduino_Bridge/PX4_Arduino_Bridge.ino`  
**الدالة:** `loop()` + `validateAndProcessFrame()`

### 7أ: المزامنة
```
USB ──CDC-ACM──▶ ATmega16U2 ──Serial──▶ ATmega2560
```
⚠️ **يتطلب DTR=1** حتى تمرر شريحة ATmega16U2 البيانات!

### 7ب: قراءة الإطار
```cpp
// البحث عن 0xAA ثم 0x55
if (incoming == SYNC_H) { bufferIndex = 1; }
if (incoming == SYNC_L && bufferIndex == 1) { syncing = false; }

// قراءة بقية الإطار
int numChannels = receiveBuffer[2];  // = 4
int expectedSize = 2 + 1 + (4 * 2) + 1;  // = 12
```

### 7ج: التحقق والتطبيق
```cpp
// التحقق من checksum
byte checksum = 0;
for (int i = 0; i < 11; i++) checksum ^= receiveBuffer[i];
if (checksum != receiveBuffer[11]) return false;  // خطأ!

// استخراج PWM وتطبيقه
for (int i = 0; i < 4; i++) {
    uint16_t pwmValue = (receiveBuffer[3 + i*2] << 8) | receiveBuffer[3 + i*2 + 1];
    // تقييد: 1000 ≤ pwmValue ≤ 2000
    motors[i].writeMicroseconds(pwmValue);
}
```

## الخطوة 8: إشارة PWM إلى ESC

**المكتبة:** `Servo.h`  
**الدالة:** `motors[i].writeMicroseconds(pwmValue)`

Arduino يُولّد إشارة PWM:
```
Pin 7  → Motor 0 → أمامي يمين (CW)   → ESC 1
Pin 11 → Motor 1 → خلفي يسار (CW)    → ESC 2
Pin 8  → Motor 2 → أمامي يسار (CCW)   → ESC 3
Pin 10 → Motor 3 → خلفي يمين (CCW)    → ESC 4
```

إشارة PWM: نبضة كل 20ms (50Hz)
```
1000µs = متوقف
1150µs = دوران بطيء (مثال: v=0.15)
1500µs = نصف سرعة
2000µs = أقصى سرعة
```

## إعداد اتصال USB (يحصل مرة واحدة عند التشغيل)

**الملف:** `UsbDeviceManager.kt` → `openDevice()`

### الترتيب:
```
1. FlightService.startCommand()
   │
   ├─▶ usbDeviceManager.start()          ← تسجيل مستقبل USB
   │     │
   │     └─▶ scanExistingDevices()        ← البحث عن أجهزة متصلة
   │           │
   │           └─▶ onDeviceAttached()     ← وجد Arduino (VID=0x2341)
   │                 │
   │                 └─▶ openDevice()
   │                       │
   │                       ├─ conn = usbManager.openDevice()
   │                       ├─ claimInterface(bulkIF, force=true)
   │                       ├─ Thread.sleep(1000)           ← استقرار USB
   │                       ├─ claimInterface(controlIF)    ← IF 0
   │                       ├─ SET_LINE_CODING (0x20)       ← 115200, 8N1
   │                       └─ SET_CONTROL_LINE_STATE (0x22)← DTR=1, RTS=1 ⚠️
   │
   ├─▶ Thread.sleep(3000)                ← انتظار اكتمال USB
   │
   └─▶ PX4Bridge.startPX4()             ← يبدأ arduino_output driver
```

### لماذا DTR مهم؟
```
بدون DTR:  Android ──USB──▶ ATmega16U2 ✘✘✘ ATmega2560
مع DTR:    Android ──USB──▶ ATmega16U2 ──▶ ATmega2560 ✓
```

## مسار الخطأ الشائع

| المشكلة | السبب | الملف |
|:--------|:------|:------|
| "sArduinoConn is null" | Arduino لم يُكتشف أو لم يُعطَ إذن USB | `UsbDeviceManager.kt` |
| "Arduino not connected" | `bulkTransfer` يرجع -1 | `arduino_output.cpp` |
| بيانات تصل لكن محرك لا يدور | DTR غير مفعّل | `UsbDeviceManager.kt` |
| checksum error على Arduino | تداخل بيانات أو baud rate خاطئ | `PX4_Arduino_Bridge.ino` |
| المحركات كلها NaN | لم يُرسل actuator_test أو لم يُسلّح | `arduino_output.cpp` |
