# شرح تفصيلي لملف PX4_Arduino_Bridge_Minimal.ino

---

## 📋 نظرة عامة

هذا الملف هو **كود Arduino** يعمل كـ **جسر اتصال (Bridge)** بين تطبيق **PX4** المُشغَّل على هاتف Android وبين **المحركات الأربعة** لطائرة بدون طيار (Drone). 

الهدف الرئيسي هو استقبال أوامر التحكم بالمحركات من التطبيق وإرسالها إلى المحركات الفعلية المتصلة بـ Arduino.

---

## 🏗️ البنية العامة للنظام

```
تطبيق PX4 (Android) 
        ↓ (عبر USB Serial)
   Arduino (هذا الكود)
        ↓ (إشارات PWM)
   المحركات الأربعة (ESCs)
```

---

## 📝 البروتوكول المستخدم

### تنسيق البيانات المُرسَلة

البيانات تصل من التطبيق إلى Arduino بتنسيق محدد:

| البايت | الوصف | القيمة |
|--------|-------|--------|
| 0 | بايت المزامنة الأول | `0xAA` |
| 1 | بايت المزامنة الثاني | `0x55` |
| 2 | عدد القنوات (المحركات) | `N` |
| 3-4 | قيمة PWM للمحرك 0 (Big Endian) | `PWM0_H` `PWM0_L` |
| 5-6 | قيمة PWM للمحرك 1 | `PWM1_H` `PWM1_L` |
| 7-8 | قيمة PWM للمحرك 2 | `PWM2_H` `PWM2_L` |
| 9-10 | قيمة PWM للمحرك 3 | `PWM3_H` `PWM3_L` |
| ... | فحص المجموع (Checksum) | `XOR` لكل الباييتات السابقة |

### مثال عملي

إذا كانت هناك 4 محركات، يكون حجم الإطار:
- **Header:** 2 بايت (`0xAA`, `0x55`)
- **عدد القنوات:** 1 بايت (`0x04`)
- **بيانات PWM:** 4 قنوات × 2 بايت = 8 بايت
- **Checksum:** 1 بايت

**المجموع:** `2 + 1 + 8 + 1 = 12 بايت`

## 🔧 الأقسام الرئيسية للكود

### 1️⃣ مكتبة Servo والمتغيرات العامة

```cpp
#include <Servo.h>

const uint8_t MOTOR_PINS[] = {7, 11, 8, 10}; // منافذ المحركات
const uint8_t NUM_MOTORS = 4;                // عدد المحركات
Servo esc[NUM_MOTORS];                       // مصفوفة كائنات المحركات
```

**الشرح:**
- يتم استخدام **منافذ Arduino الرقمية** 7، 11، 8، 10 للمحركات الأربعة
- كل محرك متصل بـ **ESC** (Electronic Speed Controller) يُتحكم به عبر إشارة PWM
- الترتيب مطابق لترتيب `actuator_outputs` في نظام PX4

---

### 2️⃣ متغيرات البروتوكول

```cpp
uint8_t buffer[32];         // مصفوفة لتخزين البيانات المستقبلة
uint8_t bufferIndex = 0;    // مؤشر الموقع الحالي في المصفوفة
bool syncFound = false;     // هل تم العثور على بايت المزامنة؟
```

**الشرح:**
- `buffer`: مساحة تخزين مؤقتة بحجم 32 بايت لاستقبال الإطار الكامل
- `bufferIndex`: يُشير إلى آخر بايت تم استقباله
- `syncFound`: علم (flag) يُشير إلى بدء الإطار (`0xAA` تم اكتشافه)

---

### 3️⃣ دالة الإعداد `setup()`

```cpp
void setup() {
  Serial.begin(115200);

  for (uint8_t i = 0; i < NUM_MOTORS; i++) {
    esc[i].attach(MOTOR_PINS[i], 900, 2100);
    esc[i].writeMicroseconds(1000);
  }

  delay(1500);
}
```

**التفصيل خطوة بخطوة:**

| الخطوة | الأمر | الغرض |
|--------|-------|-------|
| 1 | `Serial.begin(115200)` | بدء الاتصال عبر USB بسرعة 115200 بت/ثانية |
| 2 | `esc[i].attach(pin, 900, 2100)` | ربط كل محرك بالمنفذ المحدد مع نطاق 900-2100 ميكروثانية |
| 3 | `esc[i].writeMicroseconds(1000)` | إرسال إشارة التوقف الأولية (1000μs) |
| 4 | `delay(1500)` | انتظار 1.5 ثانية للسماح للمحركات بالتسليح |

**لماذا `delay(1500)`؟**
- المحركات تحتاج وقتاً لسماع نغمة "البيب" الأولى (التسليح)
- التطبيق قد يبدأ الإرسال فوراً، فلا بد من الاستعداد المُسبق

---

### 4️⃣ الحلقة الرئيسية `loop()`

```cpp
void loop() {
  while (Serial.available() > 0) {
    uint8_t incoming = Serial.read();

    if (!syncFound) {
      if (incoming == 0xAA) {
        syncFound = true;
        bufferIndex = 0;
        buffer[0] = incoming;
      }
    } else {
      buffer[++bufferIndex] = incoming;

      if (bufferIndex >= 2) {
        uint8_t numChannels = buffer[2];
        uint8_t expectedSize = 2 + 1 + (numChannels * 2) + 1;

        if (bufferIndex >= expectedSize) {
          executeCommand(expectedSize);
          syncFound = false;
        }
      }
    }
  }
}
```

**الشرح التفصيلي:**

#### المرحلة 1: البحث عن المزامنة
```
هل البايت الحالي == 0xAA؟
  ├─ نعم → سجل بداية الإطار (syncFound = true)
  └─ لا → تجاهل وابحث عن البايت التالي
```

#### المرحلة 2: استقبال البيانات
```
هل تم العثور على المزامنة مسبقاً؟
  ├─ نعم → خزّن البايت في buffer
  │        هل وصلنا للبايت رقم 2؟
  │          ├─ نعم → احسب الحجم المتوقع للإطار
  │          │        هل اكتمل الإطار؟
  │          │          ├─ نعم → نفذ الأمر (executeCommand)
  │          │          └─ لا → تابع الاستقبال
  │          └─ لا → تابع الاستقبال
  └─ لا → عد للبحث عن المزامنة
```

**ملاحظة هامة:** لا يوجد أي `Serial.print` في هذا الكود لضمان السرعة القصوى (Zero Latency)

---

### 5️⃣ دالة تنفيذ الأمر `executeCommand()`

```cpp
void executeCommand(uint8_t frameSize) {
  // 1. التحقق من Checksum
  uint8_t checksum = 0;
  for (uint8_t i = 0; i < frameSize - 1; i++) {
    checksum ^= buffer[i];
  }

  // 2. إذا كان صحيحاً، طبق القيم
  if (checksum == buffer[frameSize - 1]) {
    uint8_t numChannels = buffer[2];
    for (uint8_t i = 0; i < NUM_MOTORS && i < numChannels; i++) {
      uint16_t pwm = (buffer[3 + i * 2] << 8) | buffer[3 + i * 2 + 1];

      if (pwm < 900) pwm = 900;
      if (pwm > 2100) pwm = 2100;

      esc[i].writeMicroseconds(pwm);
    }
  }
}
```

**التفصيل خطوة بخطوة:**

#### الخطوة 1: التحقق من صحة البيانات (Checksum)

```
Checksum = XOR لكل الباييتات (ما عدا آخر بايت)
```

| العملية | الوصف |
|---------|-------|
| `checksum ^= buffer[i]` | تطبيق عملية XOR التراكمية |
| `checksum == buffer[frameSize - 1]` | مقارنة مع بايت Checksum المُستقبَل |

#### الخطوة 2: استخراج قيم PWM

**صيغة Big Endian:**
```
PWM = (البايت العالي << 8) | البايت المنخفض
```

**مثال:**
```
البايت العالي = 0x03
البايت المنخفض = 0xE8

PWM = (0x03 << 8) | 0xE8
    = 0x03E8
    = 1000 ميكروثانية
```

#### الخطوة 3: تطبيق حدود الأمان

| الحالة | الإجراء |
|--------|---------|
| `pwm < 900` | يتم ضبطه على 900 (إشارة توقف قوية) |
| `pwm > 2100` | يتم ضبطه على 2100 (الحد الأقصى الآمن) |
| `900 ≤ pwm ≤ 2100` | يُطبق كما هو |

#### الخطوة 4: إرسال الإشارة للمحرك

```cpp
esc[i].writeMicroseconds(pwm);
```

يتم إرسال إشارة PWM مباشرة إلى ESC للمحرك المحدد.

## 🔄 تدفق العمل الكامل

```
1. التطبيق يرسل إطار البيانات عبر USB
        ↓
2. Arduino يستقبل بايت بايت
        ↓
3. البحث عن 0xAA (بداية الإطار)
        ↓
4. استقبال جميع بايتات الإطار
        ↓
5. التحقق من Checksum
        ↓
6. إذا كان صحيحاً:
   ├─ استخراج قيم PWM لكل محرك
   ├─ تطبيق حدود الأمان
   └─ إرسال الإشارات للمحركات
        ↓
7. إعادة تعيين الحالة للبحث عن الإطار التالي
```

## ⚠️ ملاحظات هامة

1. **إشارة التوقف (0μs - 900μs):** التطبيق يرسل قيماً أقل من 900 لإيقاف المحركات بقوة، ويتم تعديلها إلى 900 في الكود.

2. **بدون إخراج نصي:** لا توجد أي أوامر `Serial.print` أو `Serial.println` لتجنب تأخير المحركات.

3. **سرعة الاتصال:** 115200 baud rate تضمن نقل بيانات سريع.

4. **التسليح التلقائي:** `delay(1500)` في `setup()` يسمح للمحركات بالتسليح قبل بدء استقبال الأوامر.
