## 2. المسار الكامل للبيانات (تم التحقق منه)

```
QGC Virtual Joystick
    │
    ▼ (MAVLink RC_CHANNELS_OVERRIDE عبر UDP:14550 → TCP:5760)
    │
PX4 mavlink module
    │
    ▼ (uORB: manual_control_setpoint)
    │
Manual Control → Rate/Attitude Controllers
    │
    ▼ (uORB: vehicle_torque_setpoint + vehicle_thrust_setpoint)
    │
Control Allocator (CA_ROTOR_COUNT=4, Quad-X geometry)
    │
    ▼ (uORB: actuator_motors)
    │
arduino_output driver (50 Hz)
    │
    ▼ motor[i] → PWM: 1000 + (control × 1000) μs
    │
arduino_send_pwm_via_java() (JNI → Kotlin)
    │
    ▼ بروتوكول: [0xAA][0x55][4][PWM×4][XOR]
    │
UsbDeviceManager.sendPwmDirect() (USB bulkTransfer)
    │
    ▼ (USB CDC-ACM / CH340 عبر OTG)
    │
Arduino Mega 2560 (PX4_Arduino_Bridge.ino)
    │
    ▼ Servo.writeMicroseconds(PWM)
    │
ESCs → Motors
    Pins: [7=FR, 11=BL, 8=FL, 10=BR]
```

## 3. نتائج الاختبار المباشر

### 3.1 اختبار actuator_motors مع العصا
```
# خانق مرتفع:
actuator_motors.control: [0.378, 0.622, 0.000, 1.000]

# خانق متوسط:
actuator_motors.control: [0.000, 1.000, 0.458, 0.542]

# عصا في الوضع الطبيعي (هاتف مائل على الطاولة):
actuator_motors.control: [0.106, 1.000, 0.379, 0.360]
```

**ملاحظة:** القيم غير متساوية لأن الهاتف مائل على الطاولة ومتحكم الوضعية يعوّض الميلان. المحرك 1 (rear-left) عند القيمة القصوى (1.0) بسبب ميلان الهاتف. هذا **طبيعي ومتوقع** — عند تثبيت الهاتف بشكل مستوٍ على الإطار ستكون القيم متقاربة.

### 3.2 حالة USB
- **قبل الإصلاح:** `USB:FAIL` — لأن `sArduinoConn` لم يكن يُعيَّن لأجهزة CH340
- **بعد الإصلاح:** `USB:OK` — bulkTransfer يعمل بنجاح

### 3.3 حالة الحساسات
- **IMU:** 408 عينة/ثانية (ممتاز)
- **Barometer:** يعمل (مع درجة حرارة CPU كبديل)
- **Magnetometer:** يعمل (EKF2_MAG_TYPE=6)

### 3.4 حالة التسليح
- `commander arm -f` → ينجح
- Failsafe يُفعَّل فوراً بسبب عدم وجود GPS (`local_position_invalid=True`)
- وضع `altctl` يعمل بشكل طبيعي بدون GPS

## 6. Arduino Sketch

**الملف:** `PX4_Arduino_Bridge/PX4_Arduino_Bridge.ino`  
**الحالة:** مرفوع ويعمل (5152 bytes flash)  
**البروتوكول:** `[0xAA][0x55][N][channels×2 bytes][XOR checksum]`  
**أطراف المحركات:**
| المحرك | الطرف (Pin) | الموقع | الاتجاه |
|--------|-------------|--------|---------|
| Motor 0 | Pin 7 | أمامي يمين (FR) | CW |
| Motor 1 | Pin 11 | خلفي يسار (BL) | CW |
| Motor 2 | Pin 8 | أمامي يسار (FL) | CCW |
| Motor 3 | Pin 10 | خلفي يمين (BR) | CCW |

## 8. أوامر التشغيل المرجعية

### بناء وتثبيت التطبيق:
```bash
cd /home/ash/2/AndroidApp
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### رفع سكتش الأردوينو:
```bash
arduino-cli compile --fqbn arduino:avr:mega /home/ash/2/PX4_Arduino_Bridge/
arduino-cli upload --fqbn arduino:avr:mega -p /dev/ttyUSB0 /home/ash/2/PX4_Arduino_Bridge/
```

### أوامر PX4 (MAVLink console في QGC):
```
commander mode altctl          # وضع التحكم بالارتفاع
commander arm -f               # تسليح إجباري
commander disarm               # نزع السلاح
listener actuator_motors 1     # عرض قيم المحركات
listener manual_control_setpoint 1  # عرض بيانات العصا
arduino_output status          # حالة driver الأردوينو
```

### مراقبة السجل:
```bash
adb logcat -s PX4JNI:V NativeSensor:V UsbDeviceMgr:V
```
