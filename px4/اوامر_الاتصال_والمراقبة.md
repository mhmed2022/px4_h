# أوامر الاتصال والمراقبة (الهاتف + الأردوينو)

هذا الملف يحتوي الأوامر الأساسية لتوصيل الهاتف عبر ADB على الشبكة ومراقبة اتصال الأردوينو وإرسال PWM.

## 1) الاتصال بالهاتف عبر الشبكة

```bash
adb start-server
adb connect 192.168.1.238:5555
adb devices
```

النتيجة المطلوبة في `adb devices`:
- ظهور `192.168.1.238:5555` بحالة `device`.

## 2) مراقبة PX4 + USB بشكل مباشر

```bash
adb -s 192.168.1.238:5555 logcat -s UsbDeviceMgr UsbDeviceManager PX4.px4
```

## 3) مراقبة مختصرة لنجاح/فشل إرسال PWM

```bash
adb -s 192.168.1.238:5555 logcat -v time | grep -E "sendPwmDirect|result=|USB:FAIL|Arduino not connected|Arduino connected"
```

## 4) التأكد أن الأردوينو ظاهر كنظام USB في الهاتف

```bash
adb -s 192.168.1.249:5555 shell dumpsys usb | grep -A 30 host_manager
```

علامة النجاح:
- ظهور معلومات جهاز Arduino في `host_manager`.
- ظهور `sendPwmDirect: result=12` بشكل متكرر.

## 5) تنظيف اللوق ثم بدء مراقبة نظيفة

```bash
adb -s 192.168.1.238:5555 logcat -c
adb -s 192.168.1.238:5555 logcat -s UsbDeviceMgr UsbDeviceManager PX4.px4
```

## 6) أمر واحد شامل (اتصال + بدء مراقبة)

```bash
adb start-server && adb connect 192.168.1.238:5555 && adb -s 192.168.1.238:5555 logcat -s UsbDeviceMgr UsbDeviceManager PX4.px4
```

## 7) إشارات الحالة السريعة

متصل ويعمل:
- `Arduino connected`
- `sendPwmDirect: result=12`
- عدم وجود `USB:FAIL`

غير متصل:
- `USB:FAIL`
- `Arduino not connected`
- `result<0`

## 8) إيقاف المراقبة

- اضغط `Ctrl + C`
