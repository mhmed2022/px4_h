# اوامر التسليح في المحطة

هذا الملف مرجع سريع لاوامر PX4 Shell (MAVLink Console) قبل التسليح، اثناء التسليح، وبعده.

---

## الاوامر التي طلبتها (اساسية)

```bash
listener vehicle_attitude -n 1
commander mode altctl
commander arm
listener actuator_motors -n 1
```

### معنى كل امر
- `listener vehicle_attitude -n 1`: يطبع عينة واحدة من وضعية الطائرة (roll/pitch/yaw).
- `commander mode altctl`: يحول وضع الطيران الى Altitude Control.
- `commander arm`: تسليح الطائرة (تشغيل حالة arm).
- `listener actuator_motors -n 1`: يطبع عينة واحدة من اوامر المحركات.

---

## تسلسل عملي جاهز للتشغيل (قبل التسليح -> التسليح -> التحقق)

```bash
# 1) فحص الحساسات
listener vehicle_attitude -n 1
listener sensor_accel -n 1
listener sensor_gyro -n 1

# 2) فحص حالات الarming
commander check
listener vehicle_status -n 1

# 3) اختيار وضع مناسب
commander mode altctl

# 4) تسليح
commander arm

# 5) تحقق ان اوامر المحركات تخرج
listener actuator_motors -n 1
listener actuator_outputs -n 1
```

## اوامر مفيدة جدا (وغيرها من الاوامر)

### اوامر الحالة العامة
```bash
commander status

listener vehicle_control_mode -n 1
```

### اوامر المحركات والاشارات
```bash
listener actuator_motors -n 1
listener actuator_outputs -n 1
listener actuator_armed -n 1
```

### اوامر الحساسات والاتجاه
```bash
listener vehicle_attitude -n 1
listener sensor_accel -n 1
listener sensor_gyro -n 1
listener sensor_mag -n 1
listener vehicle_local_position -n 1
```

### اوامر البارامترات (مهم للتشخيص)
```bash
param show COM_RC_IN_MODE

param show NAV_DLL_ACT
param show COM_LOW_BAT_ACT
param show COM_ARM_WO_GPS
```

### تغيير قيمة بارامتر (مثال)
```bash
param set NAV_RCL_ACT 2

param set COM_LOW_BAT_ACT 2
```

### حفظ/تحميل البارامترات
```bash
param save
param load
```

### اوامر فك التسليح والامان
```bash
commander disarm
commander mode hold
```

## سيناريو اختبار سريع للمحركات من المحطة

```bash
# تاكد ان الطائرة disarmed اولا
commander disarm

# وضع الطيران
commander mode altctl

# تسليح
commander arm

# قراءة اوامر المحركات
listener actuator_motors -n 1
listener actuator_outputs -n 1

# انهاء الاختبار
commander disarm
```

---

## تفسير قيم مهمة
- في `actuator_motors`:
  - قيمة `NaN` غالبا تعني غير مسلح/غير مفعل لهذا المحرك.
  - قيم بين `0.0` و `1.0` تعني نسبة امر دفع للمحرك.
- في `actuator_outputs`:
  - غالبا ترى PWM حول `1000` عند الخمول.
  - ترتفع القيمة مع زيادة الامر (مثل 1100, 1200, ...).

---

## ملاحظات امان مهمة
- انزع المراوح قبل اي اختبار تسليح على الطاولة.
- اذا ظهر رفض تسليح، نفذ:
  - `commander check`
  - `listener vehicle_status -n 1`
- عند اي سلوك غير طبيعي:
  - `commander disarm` فورا.

---

## اخطاء شائعة وحلها

### 1) الامر لا يعمل
- السبب: لست داخل PX4 Shell الصحيح.
- الحل: افتح MAVLink Console داخل QGC او طرفية PX4 الصحيحة.

### 2) تسليح مرفوض
- السبب: شرط preflight غير محقق.
- الحل:
```bash
commander check
listener vehicle_status -n 1
```

### 3) لا توجد اوامر للمحركات بعد arm
- السبب: وضع غير مناسب او مدخلات تحكم غير صالحة.
- الحل:
```bash
commander mode altctl
listener actuator_armed -n 1
listener actuator_motors -n 1
```
