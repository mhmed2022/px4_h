# الهبوط الاضطراري (Failsafe Land)

---

## الفكرة

عند حدوث أي مشكلة أثناء الطيران → الطائرة تهبط تلقائياً من مكانها بدلاً من الطيران بدون تحكم أو السقوط.

---

## المشاكل التي تُطلق الهبوط الاضطراري

### 1. فقد جهاز التحكم (RC Loss)
```
أغلقت QGC بالخطأ
    أو
جويستيك QGC توقف عن الإرسال
    ↓
PX4 ينتظر 0.5 ثانية
    ↓
لا توجد إشارة → هبوط تلقائي ✅
```

### 2. انقطاع الاتصال (Data Link Loss)
```
WiFi انقطع
    أو
QGC أُغلق فجأة
    ↓
PX4 ينتظر 10 ثوانٍ
    ↓
لا اتصال → هبوط تلقائي ✅
```

### 3. البطارية منخفضة (Low Battery)
```
بطارية المحركات وصلت 7%
    ↓
هبوط تلقائي ✅
(سيعمل بعد إضافة قراءة VBAT عبر Arduino)
```

---

## المعاملات التي عُدِّلت

**الملف:** `AndroidApp/app/src/main/cpp/px4_jni.cpp`

```cpp
// NAV_RCL_ACT: 2 = Land عند فقد RC (جويستيك QGC)
p = param_find("NAV_RCL_ACT");
if (p != PARAM_INVALID) {
    int32_t cur = 0; param_get(p, &cur);
    if (cur == 0) { int32_t v = 2; param_set(p, &v); }
}

// NAV_DLL_ACT: 2 = Land عند انقطاع Data Link (WiFi/QGC)
p = param_find("NAV_DLL_ACT");
if (p != PARAM_INVALID) {
    int32_t cur = 0; param_get(p, &cur);
    if (cur == 0) { int32_t v = 2; param_set(p, &v); }
}

// COM_LOW_BAT_ACT: 2 = Land عند انخفاض البطارية
p = param_find("COM_LOW_BAT_ACT");
if (p != PARAM_INVALID) {
    int32_t cur = 0; param_get(p, &cur);
    if (cur == 0) { int32_t v = 2; param_set(p, &v); }
}
```

---

## جدول قيم NAV_RCL_ACT و NAV_DLL_ACT

| القيمة | الإجراء | مناسب؟ |
|:---:|:---|:---:|
| 0 | Disabled — لا يحدث شيء | ❌ |
| 1 | Warning — تحذير فقط | ❌ |
| 2 | **Land — هبوط من مكانها** | ✅ |
| 3 | Return — عودة لنقطة الإقلاع | ⚠️ يحتاج GPS |
| 5 | Terminate — إيقاف محركات فوراً | ❌ تسقط |

---

## لماذا Land وليس Return؟

| | Return | Land |
|:---|:---:|:---:|
| يحتاج GPS | ✅ نعم | ❌ لا |
| يعمل بدون GPS | ❌ | ✅ |
| مناسب للمشروع | ❌ | ✅ |

مشروعنا لا يملك GPS → **Land هو الخيار الوحيد العملي**.

---

## حماية إعدادات المستخدم

الكود يضبط القيمة **فقط إذا كانت = 0** (لم تُضبط بعد):

```cpp
if (cur == 0) {  // ← لا يكتب فوق إعدادات المستخدم
    param_set(p, &v);
}
```

إذا غيّرت الإعداد لاحقاً من QGC → يبقى محفوظاً ✅

---

## إعدادات Timeout

| الحالة | وقت الانتظار | يمكن تغييره من |
|:---|:---:|:---|
| RC Loss | **0.5 ثانية** | QGC → Safety → RC Loss Timeout |
| Data Link Loss | **10 ثوانٍ** | QGC → Safety → Data Link Loss Timeout |
| Low Battery | فوري عند 7% | QGC → Safety → Battery Failsafe Level |

---

## التحقق من عمل الإعداد

بعد تشغيل التطبيق تحقق من logcat:
```bash
adb logcat | grep -E "NAV_RCL_ACT|NAV_DLL_ACT|COM_LOW_BAT_ACT"
```

يجب أن يظهر:
```
NAV_RCL_ACT = 2 (Land)
NAV_DLL_ACT = 2 (Land)
COM_LOW_BAT_ACT = 2 (Land)
```

أو تحقق من QGC → Safety — يجب أن يظهر **Land** في القوائم.

## ماذا يحدث عند الهبوط الاضطراري؟

```
تُفعَّل حالة Land
    ↓
PX4 يُخفّض الـ Throttle تدريجياً
    ↓
الطائرة تنخفض ببطء (~0.5 m/s)
    ↓
تكتشف لمس الأرض (by motor current drop)
    ↓
Disarm تلقائي — المحركات تتوقف ✅
```
