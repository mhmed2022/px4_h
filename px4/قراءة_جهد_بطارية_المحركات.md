# قراءة جهد بطارية المحركات عبر Arduino → PX4

---

## الهدف

جعل PX4 يرى مستوى بطارية LiPo الخاصة بالمحركات لتفعيل:
- تحذير عند 15%
- هبوط تلقائي عند 7%
- طوارئ عند 5%

---

## لماذا نحتاج Voltage Divider؟

| الجهاز | الجهد الأقصى المقبول |
|:---|:---:|
| Arduino Mega (منفذ Analog) | **5V** |
| بطارية 3S LiPo | 9.9V ~ 12.6V |
| بطارية 4S LiPo | 13.2V ~ 16.8V |

الجهد أعلى مما يتحمله Arduino → نخفّضه بمقاومتين.

---

## قطع الغيار المطلوبة

| القطعة | القيمة | الكمية |
|:---|:---:|:---:|
| مقاومة R1 | **30kΩ** (أو 33kΩ) | 1 |
| مقاومة R2 | **10kΩ** | 1 |
| سلك أحمر | — | 1 |
| سلك أسود | — | 1 |
| سلك أصفر/أخضر | — | 1 |

**التكلفة الإجمالية: أقل من دولار واحد**

## مخطط التوصيل

```
بطارية LiPo (+) ──────┬──────[R1=30kΩ]──────┐
                       │                      │
                       │              [A0 Arduino Mega]
                       │                      │
                  (للمحركات)        [R2=10kΩ]──┤
                                              │
بطارية LiPo (-) ──────────────────────────[GND Arduino]
```

### بشكل أوضح خطوة بخطوة:

```
1. سلك أحمر: من (+) LiPo → طرف R1
2. R1 (30kΩ): طرفه الآخر → نقطة وسطى
3. من النقطة الوسطى → منفذ A0 في Arduino Mega
4. R2 (10kΩ): من النقطة الوسطى → GND
5. سلك أسود: GND Arduino ← (-) LiPo
```

---

## المعادلة الرياضية

$$V_{A0} = V_{batt} \times \frac{R2}{R1 + R2} = V_{batt} \times \frac{10}{40} = V_{batt} \times 0.25$$

### جدول التحقق:

| حالة البطارية | جهد LiPo | جهد A0 |
|:---|:---:|:---:|
| شحن كامل (4S) | 16.8V | 4.20V ✅ |
| عمل طبيعي (4S) | 14.8V | 3.70V ✅ |
| منخفض (4S) | 13.2V | 3.30V ✅ |
| شحن كامل (3S) | 12.6V | 3.15V ✅ |
| عمل طبيعي (3S) | 11.1V | 2.78V ✅ |
| منخفض (3S) | 9.9V | 2.48V ✅ |

كل القيم أقل من 5V → آمنة لـ Arduino ✅

## كود Arduino (إضافة لملف الجسر الحالي)

أضف هذا الكود في ملف `PX4_Arduino_Bridge.ino`:

```cpp
// ===== قراءة جهد البطارية =====
#define VBAT_PIN A0
#define VBAT_R1  30000.0f   // 30kΩ
#define VBAT_R2  10000.0f   // 10kΩ
#define VBAT_REF 5.0f       // Arduino reference voltage
#define VBAT_SAMPLES 10     // عدد القراءات للحصول على معدل دقيق

float readBatteryVoltage() {
    long sum = 0;
    for (int i = 0; i < VBAT_SAMPLES; i++) {
        sum += analogRead(VBAT_PIN);
        delay(2);
    }
    float raw_avg = sum / (float)VBAT_SAMPLES;
    float v_pin = raw_avg * (VBAT_REF / 1023.0f);
    float v_batt = v_pin * ((VBAT_R1 + VBAT_R2) / VBAT_R2);
    return v_batt;
}
```

### في loop() أرسل الجهد كل ثانية:

```cpp
// أضف هذا في بروتوكول الإرسال
static unsigned long lastVbatTime = 0;
if (millis() - lastVbatTime > 1000) {
    float voltage = readBatteryVoltage();
    // أرسل للهاتف (أضف في بروتوكول الإرسال)
    Serial.print("VBAT:");
    Serial.println(voltage, 2);
    lastVbatTime = millis();
}
```

## كود C++ في التطبيق (arduino_output.cpp)

يجب إضافة قراءة VBAT من بروتوكول Arduino ونشره على uORB:

```cpp
#include <uORB/topics/battery_status.h>
#include <uORB/Publication.hpp>

// في ArduinoOutput class:
uORB::Publication<battery_status_s> _battery_pub{ORB_ID(battery_status)};

// عند استقبال VBAT من Arduino:
void publishBatteryVoltage(float voltage_v) {
    battery_status_s bat{};
    bat.timestamp        = hrt_absolute_time();
    bat.voltage_v        = voltage_v;
    bat.voltage_filtered_v = voltage_v;
    bat.current_a        = -1.0f;   // غير مقاس
    bat.remaining        = estimateRemaining(voltage_v);
    bat.connected        = true;
    bat.source           = battery_status_s::BATTERY_SOURCE_POWER_MODULE;
    _battery_pub.publish(bat);
}

// تقدير نسبة الشحن (4S LiPo):
float estimateRemaining(float v) {
    // 4S: 16.8V=100%  13.2V=0%
    float pct = (v - 13.2f) / (16.8f - 13.2f);
    if (pct > 1.0f) pct = 1.0f;
    if (pct < 0.0f) pct = 0.0f;
    return pct;
}
```

## معايرة القراءة (مهم)

بعد التوصيل، قس الجهد الحقيقي بـ multimeter وقارنه بما يقرأه Arduino:

```cpp
// معامل تصحيح إذا كانت المقاومات غير دقيقة
#define VBAT_CORRECTION 1.02f  // عدّل هذا حسب قراءة الـ multimeter

float v_batt = v_pin * ((VBAT_R1 + VBAT_R2) / VBAT_R2) * VBAT_CORRECTION;
```

## إعدادات QGC بعد التنفيذ

اذهب إلى **Vehicle Setup → Power** وأدخل:
- **Number of Cells**: عدد خلايا البطارية (3 أو 4)
- **Full Voltage (per cell)**: 4.2V
- **Empty Voltage (per cell)**: 3.5V

ثم **Safety → Low Battery Failsafe**:
- Battery Warn Level: **20%**
- Battery Failsafe Level: **10%** → Action: **Land**
- Battery Emergency Level: **5%** → Action: **Land immediately**

---

## تحذيرات مهمة

⚠️ **تأكد من مشاركة GND** — GND البطارية وGND Arduino يجب أن يكونا متصلين

⚠️ **لا توصّل (+) البطارية مباشرة لـ Arduino** — يجب المرور بـ Voltage Divider دائماً

⚠️ **اختبر أولاً بدون محركات** — قس جهد A0 بـ multimeter قبل توصيل Arduino

⚠️ **المقاومات يجب أن تكون ½W أو أكثر** — لتتحمل التيار
