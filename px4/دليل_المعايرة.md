# دليل المعايرة — نظام حفظ واستعادة

---

## ما هي المعايرة؟

المعايرة هي عملية تصحيح انحراف قراءات الحساسات عن القيم الحقيقية.

كل حساس فيزيائي يحتوي خطأً صغيراً ناتجاً عن:
- فوارق التصنيع
- درجة الحرارة
- الموضع الفعلي للتركيب

### الحساسات التي تحتاج معايرة:

| الحساس | ما يُصحَّح |
|:---|:---|
| **Accelerometer** (تسارع) | الإزاحة في كل محور (offset) والتدرج (scale) |
| **Gyroscope** (جيروسكوب) | الانجراف (drift) عند الثبات |
| **Magnetometer** (بوصلة) | التداخل المغناطيسي من أجزاء الطائرة |
| **Barometer** (ضغط) | الارتفاع المرجعي (يُعاير تلقائياً) |

---

## كيف تُعاير من QGC؟

1. وصّل QGC بالتطبيق عبر WiFi أو USB
2. اذهب إلى: **Vehicle Setup → Sensors**
3. اضغط **Calibrate** لكل حساس
4. اتّبع التعليمات (وضع الطائرة على 6 أوجه للـ Accel)
5. QGC تكتب النتائج مباشرة في PX4

### شروط المعايرة:
- الطائرة **غير مُسلَّحة** (Disarmed)
- اتصال MAVLink مستقر
- لا حركة أثناء معايرة Accel/Gyro
- بعيد عن معادن ومحركات أثناء معايرة Mag

---

## أين تُحفظ قيم المعايرة؟

في ملف واحد على الهاتف:
```
/sdcard/Android/data/com.ardophone.px4v17/files/px4/eeprom/parameters
```

هذا الملف يحتوي **كل** القيم مثلاً:
```
CAL_ACC0_XOFF  = -0.042
CAL_ACC0_YOFF  = +0.018
CAL_ACC0_ZOFF  = +0.215
CAL_GYRO0_XOFF = +0.001
CAL_MAG0_ROT   = 0
CAL_MAG0_PRIO  = 50
```

## نظام حماية المعايرة (التعديل الجديد)

### المشكلة التي حُلَّت:
عند إعادة تثبيت التطبيق كان ملف `eeprom/parameters` يُحذف → تضيع المعايرة.

### الحل:

**الحفظ التلقائي (كل ثانية):**
```
PX4 يعمل
    ↓ كل ثانية
SafBlackBoxMirror ينسخ:
    eeprom/parameters → فلاش USB/PX4BlackBox/eeprom/parameters
```

**الاستعادة التلقائية (عند إعادة التثبيت):**
```
فتح التطبيق بعد إعادة التثبيت
    ↓
eeprom/parameters مفقود؟
    ↓ نعم
يُستعاد تلقائياً من فلاش USB
    ↓
PX4 يبدأ بالمعايرة القديمة ✅
```

### الملفات التي عُدِّلت:
| الملف | التعديل |
|:---|:---|
| `SafBlackBoxMirror.kt` | `backupParams()` — حفظ كل ثانية |
| `SafBlackBoxMirror.kt` | `restoreParamsIfMissing()` — استعادة عند الحاجة |
| `FlightService.kt` | استدعاء restore قبل `startPX4()` |

## هيكل فلاش USB بعد الاستخدام:

```
فلاش USB/
└── PX4BlackBox/
    ├── log_001.ulg        ← سجل رحلة 1
    ├── log_002.ulg        ← سجل رحلة 2
    └── eeprom/
        └── parameters     ← نسخة احتياطية من المعايرة
```

---

## جدول الحالات:

| الحالة | النتيجة |
|:---|:---|
| فتح التطبيق عادي | params موجود → لا يحدث شيء ✅ |
| عايرت من QGC | تُنسخ للفلاش خلال ثانية ✅ |
| أعدت التثبيت + فلاش موصول | تُستعاد تلقائياً ✅ |
| أعدت التثبيت + لا فلاش | يبدأ من صفر ⚠️ |
| لا يوجد فلاش مُهيَّأ | يعمل بدون تأثير ✅ |

## ما لا تستطيع QGC معايرته:

تحويل المحاور `phone_to_frd()` في `native_sensor_reader.cpp` — ثابت في الكود:
```cpp
*nx = y;   // FRD.X = Android.Y
*ny = x;   // FRD.Y = Android.X
*nz = -z;  // FRD.Z = -Android.Z
```
إذا ركّبت الهاتف باتجاه مختلف → يجب تعديل الكود يدوياً.

---

## متطلبات تفعيل النظام:

1. وصّل فلاش USB بمحوّل OTG
2. افتح التطبيق → اضغط **BlackBox**
3. اختر مجلداً في الفلاش
4. من هذه اللحظة: كل معايرة تُحفظ تلقائياً
