## 📋 أوامر اختبار المحركات من المحطة الأرضية (MAVLink Console)

بما أننا عدنا للوضع الأصلي، إليك الأوامر الصحيحة لاختبار المحركات عبر قنطرة الاتصال (Console) من تطبيق QGroundControl:

### 1️⃣ فك التأمين (Arming)
```bash
# فك تأمين النظام للسماح بتشغيل المحركات
commander arm
```

### 2️⃣ اختبار المحركات (Actuator Test)
```bash
# تحريك المحرك الأول بنصف القوة (0.5) لمدة 3 ثوانٍ
actuator_test set -m 1 -v 0.5 -t 3

# اختبار المحرك الثاني بقوة أقل (0.3)
actuator_test set -m 2 -v 0.3 -t 3

# إيقاف المحرك يدوياً (القيمة 0.0 تعني إيقاف)
actuator_test set -m 1 -v 0.0
```

### 3️⃣ إيقاف النظام (Disarming)
```bash
# قطع الطاقة عن المحركات (إيقاف أمان)
commander disarm
```

### 📝 م همة:
- تأكد من **عدم وجود مراوح** مركبة أثناء الاختبار لضمان السلامة.
- الأمر `actuator_test` لم يعد يحرك المحركات لأن الدرايفر الآن يستمع للمسار الحقيقي (`actuator_motors`) الذي يعتمد على حركة الطائرة.
- **للمحرك الآن:** يجب استخدام **عصا التحكم (Joystick)** في QGroundControl لأن الدرايفر يتبع أوامر الطيران القياسية.

## 🔧 التعديل 3: الترقية للمسار القياسي (actuator_motors)

**الملفات المُعدّلة:**
1. `arduino_output.hpp` — تغيير الاشتراك إلى `actuator_motors.h`.
2. `arduino_output.cpp` — قراءة مصفوفة `control[]` وتحويل القيم من `[-1, 1]` إلى `[1000, 2000]`.

### المشكلة الأصلية:
في PX4 v1.17.0، تم استبدال الموضوع القديم `actuator_outputs` (الذي كان يحتوي على PWM مباشر) بموضوعين جديدين يعتمدان على المصفوفات:
- `actuator_motors` (للمحركات ESCs).
- `actuator_servos` (للسيرفوهات).

نتيجة لذلك، كان الدرايفر يستمع لموضوع لا يُنشر أبداً (`never published`).

### الحل:
تم تعديل الدرايفر ليصبح جزءاً من **المسار القياسي للطائرة (Standard Flight Path)**:
1.  **الاستماع لـ `actuator_motors`:** قراءة قيم التحكم التي يخرجها الموزع (`control_allocator`).
2.  **تحويل الإشارات:** يقوم الدرايفر بتحويل قيم التحكم العشرية (`-1.0f` إلى `1.0f`) إلى قيم PWM حقيقية (`1000` إلى `2000` ميكروثانية).
3.  **الإرسال للأردوينو:** يتم إرسال الإطارات بنفس البروتوكول الثابت.

### المعادلة البرمجية:
```cpp
// تحويل القيم المعيارية (Normalized) إلى PWM
uint16_t pwm = 1500 + (motors.control[i] * 500.0f);
```

### النتيجة النهائية:
أصبح الدرايفر يستجيب لحركة الطائرة الفعلية (عبر الـ Joystick أو الأوامر التلقائية) بدلاً من الاعتماد على أوامر الاختبار اليدوية فقط.
