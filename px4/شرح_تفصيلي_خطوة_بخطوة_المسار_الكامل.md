## 1️⃣ الخطوة الأولى: المستخدم يتحكم عبر Android App

### 🔍 ماذا يحدث بالضبط؟

#### 📱 داخل تطبيق Android

```
شاشة التطبيق (UI)
        ↓
Joystick افتراضي (دوائر تحكم)
        ↓
مستشعرات اللمس (Touch Sensors)
        ↓
إحداثيات اللمس (X, Y) لكل Joystick
        ↓
تحويل إلى قيم تحكم
```

#### 🧮 عملية التحويل بالتفصيل

**أولاً: قراءة إحداثيات اللمس**

```java
// في تطبيق Android - كود مبسط

// Joystick الأيسر (Thrust + Yaw)
float touchX = event.getX();  // إحداثيات اللمس على الشاشة
float touchY = event.getY();

// مركز Joystick
float centerX = screenWidth / 2;
float centerY = screenHeight / 2;

// حساب الإزاحة من المركز
float offsetX = (touchX - centerX) / (screenWidth / 2);   // -1.0 إلى +1.0
float offsetY = (touchY - centerY) / (screenHeight / 2);  // -1.0 إلى +1.0
```

**ثانياً: تحويل إلى قيم تحكم**

```java
// Joystick الأيسر يتحكم في: Thrust (الارتفاع) و Yaw (الدوران)
thrust = -offsetY;  // عكس المحور Y (فوق = زيادة)
yaw    = offsetX;   // يمين/يسار = دوران

// Joystick الأيمن يتحكم في: Pitch (الميلان) و Roll (الانحراف)
pitch = -offsetY2;  // أمام/خلف
roll  = offsetX2;   // يمين/يسار
```

#### 📊 مثال عملي مفصّل

```
المستخدم يحرّك Joystick الأيمن للأمام بنسبة 20%
Joystick الأيسر في المنتصف (إلا ارتفاع 70%)

النتيجة:
┌──────────────────────────────────────────────┐
│ roll  = 0.0   (لا انحراف - في المنتصف)      │
│ pitch = 0.2   (ميلان أمام 20%)              │
│ yaw   = 0.0   (لا دوران - في المنتصف)       │
│ thrust= 0.7   (ارتفاع 70%)                  │
└──────────────────────────────────────────────┘
```

### 🔌 ما يحدث في النظام

| البند | القيمة |
|-------|--------|
| **الإحداثيات** | `touchX=320, touchY=180` على شاشة `640x480` |
| **الإزاحة** | `offsetX=0.0, offsetY=-0.25` |
| **قيم التحكم** | `thrust=0.7, pitch=0.2` |
| **نوع البيانات** | `float` (-1.0 إلى +1.0) |

## 2️⃣ الخطوة الثانية: PX4 يستقبل الأوامر

### 🔍 ماذا يحدث بالضبط؟

#### 📡 استقبال البيانات

```
Android App
        ↓
USB Serial Connection
        ↓
بروتوكول MAVLink أو مخصص
        ↓
PX4 Daemon (خدمة PX4 الخلفية)
        ↓
uORB Publisher
        ↓
Topic: manual_control_setpoint
```

#### 🏗️ إنشاء Topic بالتفصيل

**تعريف Topic في PX4:**

```cpp
// ملف: msg/manual_control_setpoint.msg

uint64 timestamp            # وقت الإنشاء بالميكروثانية
float32 x                   # Pitch axis (المحور X)
float32 y                   # Roll axis  (المحور Y)

float32 r                   # Yaw axis   (المحور R)
float32 mode_switch         # مفتاح الوضع

float32 posctl_switch       # مفتاح التحكم بالموقع
float32 loiter_switch       # مفتاح الانتظار
float32 acro_switch         # مفتاح الأكرو
float32 kill_switch         # مفتاح الإيقاف
uint16 data_source          # مصدر البيانات
uint16 buttons              # الأزرار
```

**كود الإنشاء في PX4:**

```cpp
// ملف: src/modules/mavlink/mavlink_receiver.cpp

void MavlinkReceiver::handle_manual_control(
    const mavlink_manual_control_t *man)
{
    // 1. إنشاء هيكل الرسالة
    manual_control_setpoint_s manual_sp = {};
    
    // 2. تحويل القيم من MAVLink إلى PX4
    // MAVLink: 0-1000, PX4: -1.0 إلى +1.0
    manual_sp.x = (man->x - 500) / 500.0f;   // Pitch
    manual_sp.y = (man->y - 500) / 500.0f;   // Roll
    manual_sp.z = (man->z - 500) / 500.0f;   // Thrust
    manual_sp.r = (man->r - 500) / 500.0f;   // Yaw
    
    // 3. تحديد مصدر البيانات
    manual_sp.data_source = MANUAL_CONTROL_SETPOINT_SOURCE_MAVLINK;
    
    // 4. إضافة الطابع الزمني
    manual_sp.timestamp = hrt_absolute_time();
    
    // 5. نشر Topic
    _manual_control_setpoint_pub.publish(manual_sp);
}
```

#### 📊 القيم بعد الاستقبال

```
Android App أرسل:
  MAVLink x = 600  →  Pitch = (600-500)/500 = +0.2
  MAVLink y = 500  →  Roll  = (500-500)/500 =  0.0
  MAVLink z = 850  →  Thrust= (850-500)/500 = +0.7
  MAVLink r = 500  →  Yaw   = (500-500)/500 =  0.0

Topic: manual_control_setpoint
┌──────────────────────────────────────────────┐
│ x = 0.2   → Pitch (الميلان الأمامي)         │
│ y = 0.0   → Roll  (الانحراف الجانبي)        │
│ z = 0.7   → Thrust (قوة الدفع)              │
│ r = 0.0   → Yaw   (الدوران)                 │
└──────────────────────────────────────────────┘
```

#### ⚙️ ما يحدث في الخلفية

| العملية | الوصف |
|---------|-------|
| **1. الاستقبال** | USB Serial يستقبل حزمة البيانات |
| **2. فك التغليف** | إزالة Headers والتحقق من Checksum |
| **3. التحويل** | تحويل من نطاق MAVLink إلى نطاق PX4 |

## 3️⃣ الخطوة الثالثة: المتحكم يحسب المطلوب

### 🔍 ماذا يحدث بالضبط؟

#### 🧠 المتحكم (Controller) - العقل المدبر

```
manual_control_setpoint topic
        ↓
مراقبة: mc_pos_control أو mc_att_control
        ↓
PID Controller (حسابات رياضية)
        ↓
vehicle_rates_setpoint topic
```

#### 📐 حسابات PID بالتفصيل

**ما هو PID Controller؟**

PID = **Proportional + Integral + Derivative**

```
P = Kp × error          → النسبة (الخطأ الحالي)
I = Ki × ∫error dt      → التكامل (مجموع الأخطاء السابقة)
D = Kd × d(error)/dt    → التفاضل (سرعة تغير الخطأ)

output = P + I + D
```

**مثال عملي: التحكم بالارتفاع (Altitude Control)**

```
الهدف: ارتفاع 10 أمتار
الحالي: 7 أمتار

error = 10 - 7 = 3 أمتار

Kp = 0.5  →  P = 0.5 × 3 = 1.5
Ki = 0.1  →  I = 0.1 × (3 + 2.8 + 2.5 + ...) = 0.8
Kd = 0.05 →  D = 0.05 × (3 - 2) = 0.05

thrust_output = 1.5 + 0.8 + 0.05 = 2.35

(يتم قصها إلى النطاق 0.0 إلى 1.0)
thrust_output = 0.7
```

#### 🎯 المتحكم في PX4

**كود المتحكم (مبسط):**

```cpp
// ملف: src/modules/mc_att_control/MulticopterAttitudeControl.cpp

void MulticopterAttitudeControl::Run()
{
    // 1. استقبال setpoint
    _manual_control_setpoint_sub.update(&_manual_sp);
    
    // 2. قراءة حالة الطائرة الحالية
    _vehicle_attitude_sub.update(&_att);
    
    // 3. حساب الخطأ
    float roll_error  = _manual_sp.y - _att.roll;
    float pitch_error = _manual_sp.x - _att.pitch;
    float yaw_error   = _manual_sp.r - _att.yaw;
    
    // 4. تطبيق PID
    float roll_rate  = _pid_roll.roll(roll_error, dt);
    float pitch_rate = _pid_pitch.pitch(pitch_error, dt);
    float yaw_rate   = _pid_yaw.yaw(yaw_error, dt);
    
    // 5. إنشاء rates setpoint
    vehicle_rates_setpoint_s rates_sp;
    rates_sp.roll  = roll_rate;   // rad/s
    rates_sp.pitch = pitch_rate;  // rad/s
    rates_sp.yaw   = yaw_rate;    // rad/s
    rates_sp.thrust = _manual_sp.z;
    
    // 6. نشر
    _rates_sp_pub.publish(rates_sp);
}
```

#### 📊 النتيجة

```
المدخلات:
  roll  = 0.0
  pitch = 0.2
  yaw   = 0.0
  thrust= 0.7

الحسابات:
  الخطأ الحالي = 0.2 - 0.0 = 0.2 (pitch)
  PID يحسب rate المطلوب
  
المخرجات:
┌──────────────────────────────────────────────┐
│ vehicle_rates_setpoint:                      │
│   roll  = 0.0  rad/s  (لا دوران)            │
│   pitch = 0.5  rad/s  (ميلان أمامي)         │
│   yaw   = 0.0  rad/s  (لا دوران)            │
│   thrust= 0.7          (قوة الدفع)           │
└──────────────────────────────────────────────┘
```

#### ⚙️ ما يحدث بالتفصيل

| العملية | الوصف |
|---------|-------|
| **1. القراءة** | قراءة `manual_control_setpoint` |
| **2. القياس** | قراءة حالة الطائرة الحالية (Attitude) |
| **3. الخطأ** | حساب الفرق بين المطلوب والفعلي |
| **4. الحساب** | PID يحسب rates المطلوبة |
| **5. النشر** | `vehicle_rates_setpoint` يُنشر |

## 4️⃣ الخطوة الرابعة: Mixer يوزع القيم

### 🔍 ماذا يحدث بالضبط؟

#### 🔄 ما هو Mixer؟

**Mixer** = آلة توزيع القوى - هو الجزء الذي يقرر **كم يجب أن يدور كل محرك** لتحقيق rates المطلوبة.

```
vehicle_rates_setpoint
        ↓
┌─────────────────────────────────┐
│ Mixer (الخلاط)                  │
│                                 │
│ لكل محرك:                       │
│   output = (thrust × coef)      │
│          + (roll × coef)        │
│          + (pitch × coef)       │
│          + (yaw × coef)         │
└─────────────────────────────────┘
        ↓
قيم لكل محرك (-1.0 إلى +1.0)
```

#### 📐 معادلات Mixer بالتفصيل

**للطائرة الرباعية (QUADROTOR_X):**

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│     M0 (أمامي يمين - CW)        M2 (خلفي يسار - CCW)  │
│           ↗                          ↖                 │
│              ╲                    ╱                    │
│                 ╲              ╱                       │
│                    ╲        ╱                          │
│                       ╲  ╱                             │
│                        ◇                               │
│                       ╱  ╲                             │
│                    ╱        ╲                          │
│                 ╱              ╲                       │
│              ╱                    ╲                    │
│           ↙                          ↘                 │
│     M1 (أمامي يسار - CCW)      M3 (خلفي يمين - CW)    │
│                                                        │
└────────────────────────────────────────────────────────┘
```

**معادلة التوزيع:**

```
Motor 0 = thrust - roll  + pitch - yaw    (أمامي يمين - CW)
Motor 1 = thrust + roll  + pitch + yaw    (أمامي يسار - CCW)
Motor 2 = thrust + roll  - pitch + yaw    (خلفي يسار - CCW)
Motor 3 = thrust - roll  - pitch - yaw    (خلفي يمين - CW)
```

**لماذا هذه الإشارات؟**

| المحرك | الدوران | تأثير زيادة سرعته |
|--------|---------|-------------------|
| M0 | Clockwise (CW) | يدفع للأمام + يمين |
| M1 | Counter-CW (CCW) | يدفع للأمام + يسار |
| M2 | Counter-CW (CCW) | يدفع للخلف + يسار |
| M3 | Clockwise (CW) | يدفع للخلف + يمين |

#### 🧮 مثال عملي مفصّل

```
المدخلات:
  thrust = 0.7
  roll   = 0.0
  pitch  = 0.2
  yaw    = 0.0

الحساب خطوة بخطوة:

Motor 0 = 0.7 - 0.0 + 0.2 - 0.0
        = 0.9

Motor 1 = 0.7 + 0.0 + 0.2 + 0.0
        = 0.9

Motor 2 = 0.7 + 0.0 - 0.2 + 0.0
        = 0.5

Motor 3 = 0.7 - 0.0 - 0.2 - 0.0
        = 0.5

النتيجة:
┌──────────────────────────────────────────┐
│ Motor 0 (أمامي يمين)  = 0.9  (90%)      │
│ Motor 1 (أمامي يسار)  = 0.9  (90%)      │
│ Motor 2 (خلفي يسار)   = 0.5  (50%)      │
│ Motor 3 (خلفي يمين)   = 0.5  (50%)      │
└──────────────────────────────────────────┘
```

#### 📝 كود Mixer في PX4

```cpp
// ملف: src/lib/mixer_module/multirotor_airframe_types/multirotor_mixer.cpp

void MultirotorMixer::mix()
{
    // لكل محرك
    for (int i = 0; i < _num_motors; i++) {
        
        float output = 0.0f;
        
        // توزيع القيم
        output += _thrust_scaling     * thrust;
        output += _roll_scaling[i]    * roll;
        output += _pitch_scaling[i]   * pitch;
        output += _yaw_scaling[i]     * yaw;
        
        // قص إلى النطاق الآمن
        if (output > 1.0f) output = 1.0f;
        if (output < -1.0f) output = -1.0f;
        
        _outputs[i] = output;
    }
}

// مثال لمصفوفات التوزيع (QUADROTOR_X):
_roll_scaling  = [-0.5, +0.5, +0.5, -0.5]
_pitch_scaling = [+0.5, +0.5, -0.5, -0.5]
_yaw_scaling   = [-0.5, +0.5, +0.5, -0.5]
```

#### ⚠️ لماذا هذا التوزيع؟

**الميلان للأمام (Pitch > 0):**

```
زيادة سرعة المحركات الأمامية (M0, M1)
نقصان سرعة المحركات الخلفية (M2, M3)
        ↓
الجزء الأمامي يرتفع
الجزء الخلفي ينخفض
        ↓
الطائرة تميل للأمام ← تتحرك للأمام
```

#### ⚙️ ما يحدث بالتفصيل

| العملية | الوصف |
|---------|-------|
| **1. الاستقبال** | قراءة `vehicle_rates_setpoint` |
| **2. الضرب** | ضرب كل قيمة في معاملها |
| **3. الجمع** | جمع المساهمات لكل محرك |
| **4. القص** | قص القيم إلى النطاق (-1.0, +1.0) |
| **5. الإخراج** | إنشاء مصفوفة `outputs` |

## 5️⃣ الخطوة الخامسة: إنشاء actuator_outputs

### 🔍 ماذا يحدث بالضبط؟

#### 🔄 من Mixer Output إلى PWM

```
Mixer Output (-1.0 إلى +1.0)
        ↓
تحويل إلى PWM (900-2100 μs)
        ↓
PWM = center + (output × range)
        ↓
actuator_outputs topic
```

#### 📐 معادلة التحويل بالتفصيل

```
PWM = center + (output × range)

حيث:
  center = 1500 μs  (القيمة المتوسطة)
  range  = 500 μs   (نطاق التغير)

أمثلة:
┌────────────────────────────────────────────┐
│ output = -1.0  →  PWM = 1500 - 500 = 1000 │
│ output = -0.5  →  PWM = 1500 - 250 = 1250 │
│ output =  0.0  →  PWM = 1500 + 0   = 1500 │
│ output = +0.5  →  PWM = 1500 + 250 = 1750 │
│ output = +1.0  →  PWM = 1500 + 500 = 2000 │
└────────────────────────────────────────────┘
```

#### 🧮 مثال عملي مفصّل

```
المخرجات من Mixer:
  Motor 0 = 0.9
  Motor 1 = 0.9
  Motor 2 = 0.5
  Motor 3 = 0.5

التحويل إلى PWM:

Motor 0: PWM = 1500 + (0.9 × 500) = 1500 + 450 = 1950 μs
Motor 1: PWM = 1500 + (0.9 × 500) = 1500 + 450 = 1950 μs
Motor 2: PWM = 1500 + (0.5 × 500) = 1500 + 250 = 1750 μs
Motor 3: PWM = 1500 + (0.5 × 500) = 1500 + 250 = 1750 μs

النتيجة:
┌──────────────────────────────────────────────┐
│ actuator_outputs_s:                          │
│   noutputs = 4                               │
│   output[0] = 0.9, pwm[0] = 1950             │
│   output[1] = 0.9, pwm[1] = 1950             │
│   output[2] = 0.5, pwm[2] = 1750             │
│   output[3] = 0.5, pwm[3] = 1750             │
└──────────────────────────────────────────────┘
```

#### 📝 كود الإنشاء في PX4

```cpp
// ملف: src/lib/mixer_module/MixerModule.cpp

void MixerModule::update_outputs()
{
    // 1. قراءة mixer outputs
    float outputs[MAX_ACTUATORS];
    mixer.mix(outputs);
    
    // 2. تحويل إلى PWM
    actuator_outputs_s actuator_out = {};
    actuator_out.noutputs = _num_outputs;
    
    for (int i = 0; i < _num_outputs; i++) {
        // تطبيق حدود أمان
        float output = math::constrain(outputs[i], -1.0f, 1.0f);
        
        // تحويل إلى PWM
        uint16_t pwm = 1500 + (output * 500);
        
        // تطبيق حدود PWM
        pwm = math::constrain(pwm, 900, 2100);
        
        // تخزين
        actuator_out.output[i] = output;
        actuator_out.pwm[i] = pwm;
    }
    
    // 3. إضافة الطابع الزمني
    actuator_out.timestamp = hrt_absolute_time();
    
    // 4. نشر topic
    _actuator_outputs_pub.publish(actuator_out);
}
```

#### ⚙️ ما يحدث بالتفصيل

| العملية | الوصف |
|---------|-------|
| **1. القراءة** | قراءة `mixer outputs` |
| **2. التحويل** | تحويل من float إلى PWM |
| **3. الحدود** | قص القيم إلى (900-2100) |
| **4. التخزين** | تخزين في `actuator_outputs_s` |
| **5. النشر** | نشر عبر uORB |

## 6️⃣ الخطوة السادسة: Android App يقرأ البيانات

### 🔍 ماذا يحدث بالضبط؟

#### 📱 داخل تطبيق Android

```
PX4 (actuator_outputs topic)
        ↓
uORB Subscription
        ↓
قراءة القيم
        ↓
تحويل إلى Bytes
        ↓
تطبيق البروتوكول
        ↓
إرسال عبر USB Serial
```

#### 📝 كود القراءة (مبسط)

```java
// في تطبيق Android

// 1. الاشتراك في topic
Subscription<ActuatorOutputs> actuatorSub = 
    new Subscription<>(ActuatorOutputs.class);

// 2. قراءة البيانات
ActuatorOutputs outputs = actuatorSub.take();

// 3. استخراج قيم PWM
int[] pwmValues = outputs.getPwm();  // [1950, 1950, 1750, 1750]

// 4. تحويل إلى bytes
byte[] data = buildProtocolFrame(pwmValues);

// 5. إرسال عبر USB
usbSerial.write(data);
```

#### 🔧 بناء إطار البروتوكول بالتفصيل

```java
private byte[] buildProtocolFrame(int[] pwm) {
    int numChannels = pwm.length;  // 4
    int frameSize = 2 + 1 + (numChannels * 2) + 1;  // 12
    
    byte[] frame = new byte[frameSize];
    
    // Header
    frame[0] = (byte) 0xAA;
    frame[1] = (byte) 0x55;
    
    // عدد القنوات
    frame[2] = (byte) numChannels;
    
    // قيم PWM (Big Endian)
    int index = 3;
    for (int i = 0; i < numChannels; i++) {
        frame[index++] = (byte) ((pwm[i] >> 8) & 0xFF);  // High byte
        frame[index++] = (byte) (pwm[i] & 0xFF);         // Low byte
    }
    
    // Checksum
    byte checksum = 0;
    for (int i = 0; i < frameSize - 1; i++) {
        checksum ^= frame[i];
    }
    frame[frameSize - 1] = checksum;
    
    return frame;
}
```

#### 🧮 مثال عملي مفصّل

```
قيم PWM:
  Motor 0 = 1950 = 0x079E
  Motor 1 = 1950 = 0x079E
  Motor 2 = 1750 = 0x06D6
  Motor 3 = 1750 = 0x06D6

بناء الإطار:

Index  | القيمة    | الوصف
-------|-----------|------------------
0      | 0xAA      | Header byte 1
1      | 0x55      | Header byte 2
2      | 0x04      | عدد القنوات (4)
3      | 0x07      | Motor 0 High
4      | 0x9E      | Motor 0 Low
5      | 0x07      | Motor 1 High
6      | 0x9E      | Motor 1 Low
7      | 0x06      | Motor 2 High
8      | 0xD6      | Motor 2 Low
9      | 0x06      | Motor 3 High
10     | 0xD6      | Motor 3 Low
11     | Checksum  | XOR كل ما سبق

حساب Checksum:
  0xAA ^ 0x55 ^ 0x04 ^ 0x07 ^ 0x9E ^ 0x07 ^ 0x9E ^ 0x06 ^ 0xD6 ^ 0x06 ^ 0xD6
  = 0x2A

الإطار النهائي:
┌────────────────────────────────────────────────────┐
│ [AA][55][04][07][9E][07][9E][06][D6][06][D6][2A] │
└────────────────────────────────────────────────────┘
```

## 7️⃣ الخطوة السابعة: إرسال عبر USB Serial

### 🔍 ماذا يحدث بالضبط؟

#### 🔌 اتصال USB

```

        ↓

        ↓
```

#### 📡 عملية الإرسال بالتفصيل

```

        ↓
```

#### 📊 تفاصيل الإرسال

| البند | القيمة |
|-------|--------|
| **السرعة** | 115200 bits/second |
| **نوع البيانات** | 12 بايت لكل إطار |

```
12 بايت × 8 bits = 96 bits

96 bits ÷ 115200 bps = 0.00083 ثانية = 0.83ms

≈ 1ms لكل إطار
```

| **4. الاستقبال** | USB controller في Arduino |

## 8️⃣ الخطوة الثامنة: Arduino يستقبل ويُطبق

### 🔍 ماذا يحدث بالضبط؟

#### 📥 استقبال البيانات

```
USB Cable
        ↓
UART Receive Buffer
        ↓
Serial.read() → بايت بايت
        ↓
buffer[] في Arduino
        ↓
البحث عن 0xAA
        ↓
استقبال الإطار الكامل
        ↓
executeCommand()
```

#### 📝 الكود بالتفصيل

```cpp
// في Arduino

void loop() {
  while (Serial.available() > 0) {
    uint8_t incoming = Serial.read();
    
    if (!syncFound) {
      // البحث عن بداية الإطار
      if (incoming == 0xAA) {
        syncFound = true;
        bufferIndex = 0;
        buffer[0] = incoming;
      }
    } else {
      buffer[++bufferIndex] = incoming;
      
      // إذا وصلنا لبايت عدد القنوات
      if (bufferIndex >= 2) {
        uint8_t numChannels = buffer[2];
        uint8_t expectedSize = 2 + 1 + (numChannels * 2) + 1;
        
        if (bufferIndex >= expectedSize) {
          executeCommand(expectedSize);
          syncFound = false;
        }
      }
    }
  }
}
```

#### 🧮 executeCommand() بالتفصيل

```cpp
void executeCommand(uint8_t frameSize) {
  // 1. حساب Checksum
  uint8_t checksum = 0;
  for (uint8_t i = 0; i < frameSize - 1; i++) {
    checksum ^= buffer[i];
  }
  
  // 2. التحقق
  if (checksum == buffer[frameSize - 1]) {
    // 3. استخراج قيم PWM
    uint8_t numChannels = buffer[2];
    
    for (uint8_t i = 0; i < NUM_MOTORS && i < numChannels; i++) {
      // Big Endian: High byte أولاً
      uint16_t pwm = (buffer[3 + i*2] << 8) | buffer[3 + i*2 + 1];
      
      // حدود أمان
      if (pwm < 900) pwm = 900;
      if (pwm > 2100) pwm = 2100;
      
      // تطبيق القيمة
      esc[i].writeMicroseconds(pwm);
    }
  }
}
```

#### 🧮 مثال عملي مفصّل

```
البايتات المستقبلة:
  [AA][55][04][07][9E][07][9E][06][D6][06][D6][2A]

استخراج Motor 0:
  High = 0x07
  Low  = 0x9E
  
  PWM = (0x07 << 8) | 0x9E
      = 0x079E
      = 1950

استخراج Motor 1:
  High = 0x07
  Low  = 0x9E
  
  PWM = (0x07 << 8) | 0x9E
      = 0x079E
      = 1950

استخراج Motor 2:
  High = 0x06
  Low  = 0xD6
  
  PWM = (0x06 << 8) | 0xD6
      = 0x06D6
      = 1750

استخراج Motor 3:
  High = 0x06
  Low  = 0xD6
  
  PWM = (0x06 << 8) | 0xD6
      = 0x06D6
      = 1750

تطبيق القيم:
  esc[0].writeMicroseconds(1950)  → Motor 0
  esc[1].writeMicroseconds(1950)  → Motor 1
  esc[2].writeMicroseconds(1750)  → Motor 2
  esc[3].writeMicroseconds(1750)  → Motor 3
```

## 9️⃣ الخطوة التاسعة: ESCs تتحكم بالمحركات

### 🔍 ماذا يحدث بالضبط؟

#### 🔌 ما هو ESC؟

**ESC = Electronic Speed Controller**

```
إشارة PWM من Arduino (900-2100 μs)
        ↓
ESC يقرأ عرض النبضة
        ↓
يتحكم في سرعة المحرك
        ↓
المحرك يدور بالسرعة المطلوبة
```

#### 📊 علاقة PWM بالسرعة

| PWM | العرض (μs) | السرعة |
|-----|------------|--------|
| 900 | 900 | إيقاف قوي (0%) |
| 1000 | 1000 | إيقاف (0%) |
| 1100 | 1100 | بطيء (10%) |
| 1250 | 1250 | منخفض (25%) |
| 1500 | 1500 | متوسط (50%) |
| 1750 | 1750 | عالي (75%) |
| 1950 | 1950 | عالي جداً (95%) |
| 2000 | 2000 | أقصى (100%) |
| 2100 | 2100 | أقصى حد (100%+) |

#### 🧮 مثال عملي مفصّل

```
PWM المستقبلة:
  Motor 0 = 1950 μs
  Motor 1 = 1950 μs
  Motor 2 = 1750 μs
  Motor 3 = 1750 μs

تحويل إلى سرعة:
  Motor 0: (1950 - 1000) / (2000 - 1000) × 100% = 95%
  Motor 1: (1950 - 1000) / (2000 - 1000) × 100% = 95%
  Motor 2: (1750 - 1000) / (2000 - 1000) × 100% = 75%
  Motor 3: (1750 - 1000) / (2000 - 1000) × 100% = 75%

النتيجة:
┌──────────────────────────────────────────────┐
│ Motor 0 (أمامي يمين)  = 95% سرعة            │
│ Motor 1 (أمامي يسار)  = 95% سرعة            │
│ Motor 2 (خلفي يسار)   = 75% سرعة            │
│ Motor 3 (خلفي يمين)   = 75% سرعة            │
└──────────────────────────────────────────────┘
```

#### 🔧 كيف يعمل ESC داخلياً؟

```
1. يستقبل إشارة PWM
        ↓
2. يقيس عرض النبضة (Pulse Width)
        ↓
3. يحسب نسبة السرعة المطلوبة
        ↓
4. يُرسل تيار ثلاثي الأطوار (3-phase) إلى المحرك
        ↓
5. المحرك يدور بالسرعة المطلوبة
```

#### ⚙️ ما يحدث بالتفصيل

| العملية | الوصف |
|---------|-------|
| **1. الاستقبال** | PWM signal من Arduino |
| **2. القياس** | قياس عرض النبضة |
| **3. الحساب** | تحويل إلى نسبة سرعة |
| **4. التحكم** | التحكم في التيار عبر MOSFETs |
| **5. الدوران** | المحرك يدور بالسرعة المطلوبة |

## 🔟 الخطوة العاشرة: الطائرة تتحرك

### 🔍 ماذا يحدث بالضبط؟

#### 🚁 تحليل الحركة

```
المحركات الأربعة تدور بسرعات مختلفة
        ↓
فرق القوى بين المحركات
        ↓
عزم دوران (Torque)
        ↓
الطائرة تميل/تدور/ترتفع
        ↓
الحركة المطلوبة تتحقق
```

#### 🧮 مثال عملي: الميلان للأمام

```
السيناريو: pitch = 0.2 (ميلان أمام 20%)

القوى:
  Motor 0 (أمامي يمين)  = 95% قوة
  Motor 1 (أمامي يسار)  = 95% قوة
  Motor 2 (خلفي يسار)   = 75% قوة
  Motor 3 (خلفي يمين)   = 75% قوة

القوة الكلية:
  Front = M0 + M1 = 95% + 95% = 190%
  Rear  = M2 + M3 = 75% + 75% = 150%

النتيجة:
  Front > Rear
        ↓
  الجزء الأمامي يرتفع
  الجزء الخلفي ينخفض
        ↓
  الطائرة تميل للأمام
        ↓
  الطائرة تتحرك للأمام
```

#### 📊 تحليل العزوم

```
Pitch Moment (عزم الميلان):
  = (Front Force - Rear Force) × arm_length
  = (190% - 150%) × L
  = 40% × L

Roll Moment (عزم الانحراف):
  = (Right Force - Left Force) × arm_length
  = (95% + 75%) - (95% + 75%) = 0

Yaw Moment (عزم الدوران):
  = (CW Motors - CCW Motors) × torque_coef
  = (M0 + M3) - (M1 + M2)
  = (95% + 75%) - (95% + 75%) = 0
```

#### 🎯 النتيجة النهائية

| الحركة | القيم | التأثير |
|--------|-------|---------|
| Pitch | M0=95%, M1=95%, M2=75%, M3=75% | ميلان للأمام |
| Roll | متساوي يمين/يسار | لا انحراف |
| Yaw | CW = CCW | لا دوران |
| Thrust | متوسط 85% | ارتفاع |
