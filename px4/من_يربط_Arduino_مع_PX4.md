# من يربط Arduino مع PX4؟

---

## 🎯 الإجابة المباشرة

**تطبيق Android** هو الجسر الذي يربط بين PX4 و Arduino.

---

## 🔍 التفصيل: كيف يعمل الجسر؟

### 1️⃣ PX4 (المرسل)

| البند | القيمة |
|-------|--------|
| **الموقع** | يعمل على Android phone (companion computer) |
| **المخرج** | `actuator_outputs` topic |
| **نوع البيانات** | `uint16_t pwm[4]` (900-2100 μs) |

```
PX4 ينتج:
  pwm[0] = 1950
  pwm[1] = 1950
  pwm[2] = 1750
  pwm[3] = 1750
```

---

### 2️⃣ تطبيق Android (الجسر)

| البند | القيمة |
|-------|--------|
| **الوظيفة** | قراءة البيانات من PX4 → إرسال إلى Arduino |
| **المصدر** | `actuator_outputs` topic (uORB) |
| **الوجهة** | USB Serial Port |
| **البروتوكول** | `[0xAA][0x55][N][PWM_H][PWM_L]...[Checksum]` |

#### 📝 ما يفعله التطبيق بالتفصيل

```
1. يقرأ actuator_outputs من PX4
        ↓
2. يستخرج قيم PWM
        ↓
3. يبني الإطار:
   [0xAA][0x55][4][PWM0_H][PWM0_L]...[Checksum]
        ↓
4. يرسل عبر USB Serial إلى Arduino
```

#### 🧮 مثال عملي

```
PX4 أرسل:
  pwm[0] = 1950
  pwm[1] = 1950
  pwm[2] = 1750
  pwm[3] = 1750

تطبيق Android يبني:
  [AA][55][04][07][9E][07][9E][06][D6][06][D6][2A]
  
  Index  | القيمة | الوصف
  -------|--------|------------------
  0      | 0xAA   | Header
  1      | 0x55   | Header
  2      | 0x04   | عدد القنوات (4)
  3      | 0x07   | Motor 0 High
  4      | 0x9E   | Motor 0 Low
  5      | 0x07   | Motor 1 High
  6      | 0x9E   | Motor 1 Low
  7      | 0x06   | Motor 2 High
  8      | 0xD6   | Motor 2 Low
  9      | 0x06   | Motor 3 High
  10     | 0xD6   | Motor 3 Low
  11     | 0x2A   | Checksum
```

---

### 3️⃣ USB Serial (الوسيط الفيزيائي)

| البند | القيمة |
|-------|--------|
| **نوع الاتصال** | USB OTG |
| **السرعة** | 115200 baud |
| **الاتجاه** | Android → Arduino |
| **البيانات** | 12 بايت لكل إطار |

```
Android Phone ─── USB Cable ─── Arduino
```

---

### 4️⃣ Arduino (المستقبل)

| البند | القيمة |
|-------|--------|
| **الاستقبال** | USB Serial (Serial.read()) |
| **البروتوكول** | يبحث عن 0xAA 0x55 |
| **المعالجة** | executeCommand() |
| **الإخراج** | PWM Signals على GPIO pins |

```
Arduino يستقبل:
  [AA][55][04][07][9E][07][9E][06][D6][06][D6][2A]
        ↓
يستخرج:
  pwm[0] = 1950
  pwm[1] = 1950
  pwm[2] = 1750
  pwm[3] = 1750
        ↓
يطبق:
  esc[0].writeMicroseconds(1950)
  esc[1].writeMicroseconds(1950)
  esc[2].writeMicroseconds(1750)
  esc[3].writeMicroseconds(1750)
```

## 📋 ملخص الأدوار

| العنصر | الدور | الوظيفة |
|--------|-------|---------|
| **PX4** | المرسل | يُولد قيم PWM من الحسابات |
| **تطبيق Android** | **الجسر** | يقرأ من PX4 ويرسل إلى Arduino |
| **USB Cable** | الوسيط | نقل البيانات الفيزيائي |
| **Arduino** | المستقبل | يستقبل ويطبق على المحركات |

## 🔗 لماذا نحتاج تطبيق Android كجسر؟

### السؤال: لماذا لا يتصل Arduino مباشرة مع PX4؟

| السبب | الشرح |
|-------|-------|
| **PX4 لا يدعم Arduino مباشرة** | PX4 يعمل على نظام مختلف ولا يعرف عن Arduino |
| **بروتوكولات مختلفة** | PX4 يستخدم uORB، Arduino يستخدم Serial |
| **تطبيق Android يترجم** | يحوّل من uORB إلى Serial protocol |

### البديل

```
بدون تطبيق Android كجسر:
  PX4 ──❌── Arduino
  (لا يفهمون بعض)

مع تطبيق Android:
  PX4 ──✅── Android ──✅── Arduino
  (يترجم البروتوكولات)
```

## ⚠️ ملاحظات هامة

1. **تطبيق Android هو الجسر الحقيقي** - بدونه لا يوجد اتصال.

2. **البروتوكول مخصص** - `[0xAA][0x55]` ليس MAVLink، بل بروتوكول خاص.

3. **الاتصال أحادي الاتجاه** - من PX4 إلى Arduino فقط (في هذا المشروع).

4. **السرعة مهمة** - USB Serial بسرعة 115200 baud.
