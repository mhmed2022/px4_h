# دليل اختبار تدفق البيانات وتحديد نقطة التوقف

---

## 🎯 الهدف

هذا الدليل يوضح **كيف تختبر كل مرحلة** من مراحل تدفق البيانات في مشروعك، و**كيف تعرف أين تتوقف البيانات** إذا كان هناك مشكلة.

---

## 📊 خريطة مراحل تدفق البيانات

```
PX4 → تطبيق Android → USB Serial → Arduino → ESCs → Motors
```

| المرحلة | من | إلى |
|---------|----|-----|
| 1 | PX4 | تطبيق Android |
| 2 | تطبيق Android | USB Serial |
| 3 | USB Serial | Arduino |
| 4 | Arduino | ESCs |
| 5 | ESCs | Motors |

## 🧪 اختبار كل مرحلة بالتفصيل

### المرحلة 1: اختبار PX4 → تطبيق Android

#### 🔍 السؤال: هل PX4 يُرسل البيانات؟

##### ✅ طريقة الاختبار

**داخل تطبيق Android:**

```java
// أضف هذا الكود في Android App للاختبار

// 1. اشترك في topic
Subscription<ActuatorOutputs> actuatorSub = 
    new Subscription<>(ActuatorOutputs.class);

// 2. اقرأ البيانات
ActuatorOutputs outputs = actuatorSub.take();

// 3. اطبع القيم (للاختبار فقط)
Log.d("TEST", "actuator_outputs: " +
      "noutputs=" + outputs.noutputs +
      ", pwm[0]=" + outputs.pwm[0] +
      ", pwm[1]=" + outputs.pwm[1] +
      ", pwm[2]=" + outputs.pwm[2] +
      ", pwm[3]=" + outputs.pwm[3]);
```

##### 📊 النتائج المتوقعة

| إذا ظهر | النتيجة |
|---------|---------|
| `noutputs=4, pwm=[1500,1500,1500,1500]` | ✅ PX4 يعمل ويُرسل |
| `noutputs=0` أو قيم فارغة | ❌ PX4 لا يُرسل |
| لا يظهر شيء | ❌ subscription لا يعمل |

##### 🔧 كيف تعرف إذا كانت المشكلة من PX4؟

```
1. تحقق من حالة PX4:
   - هل هو armed؟
   - هل هناك أخطاء في النظام؟

2. تحقق من topic:
   - هل actuator_outputs يُنشر؟
   - استخدم: uorb top actuator_outputs

3. تحقق من التطبيق:
   - هل subscription صحيح؟
```

### المرحلة 2: اختبار تطبيق Android → USB Serial

#### 🔍 السؤال: هل التطبيق يُرسل البيانات عبر USB؟

##### ✅ طريقة الاختبار

**أ) اختبار داخلي في Android:**

```java
// أضف هذا الكود بعد بناء الإطار

// 1. اطبع البيانات قبل الإرسال
Log.d("TEST", "Building frame:");
Log.d("TEST", "  Motor 0 PWM = " + pwm[0]);
Log.d("TEST", "  Motor 1 PWM = " + pwm[1]);
Log.d("TEST", "  Motor 2 PWM = " + pwm[2]);
Log.d("TEST", "  Motor 3 PWM = " + pwm[3]);

// 2. اطبع الإطار الكامل
StringBuilder sb = new StringBuilder();
for (byte b : frame) {
    sb.append(String.format("%02X ", b));
}
Log.d("TEST", "Frame to send: " + sb.toString());

// 3. تحقق من الإرسال
int bytesSent = usbSerial.write(frame);
Log.d("TEST", "Bytes sent: " + bytesSent);
```

**ب) استخدام أداة خارجية:**

```bash
# على الكمبيوتر (إذا كان Arduino متصل بالكمبيوتر)
# استخدم Serial Monitor لاختبار الإرسال

# 1. افتح Arduino IDE
# 2. افتح Serial Monitor
# 3. اضبط على 115200 baud
# 4. تحقق من استقبال البيانات
```

##### 📊 النتائج المتوقعة

| إذا ظهر | النتيجة |
|---------|---------|
| `Bytes sent: 12` | ✅ الإرسال نجح |
| `Bytes sent: 0` أو خطأ | ❌ USB لا يعمل |
| `Serial timeout` | ❌ Arduino غير متصل |

##### 🔧 كيف تعرف إذا كانت المشكلة من USB؟

```
1. تحقق من اتصال USB:
   - هل الكابل متصل؟
   - هل Arduino يظهر في lsusb؟

2. تحقق من الأذونات:
   - هل التطبيق لديه إذن USB؟
   - USB_PERMISSION granted؟

3. تحقق من الإعدادات:
   - Baud rate = 115200؟
   - USB Device موجود؟
```

### المرحلة 3: اختبار USB Serial → Arduino

#### 🔍 السؤال: هل Arduino يستقبل البيانات؟

##### ✅ طريقة الاختبار

**أ) اختبار استقبال بسيط (للتصحيح فقط):**

```cpp
// أضف هذا الكود في Arduino (للاختبار فقط - احذفه لاحقاً)

uint8_t testCounter = 0;

void loop() {
  if (Serial.available() > 0) {
    uint8_t incoming = Serial.read();
    
    // اطبع كل بايت مستلم (للاختبار)
    if (testCounter % 100 < 10) {  // اطبع أول 10 بايتات فقط
      Serial.print("Received byte: ");
      Serial.println(incoming, HEX);
    }
    testCounter++;
  }
}
```

**ب) اختبار أفضل - عداد الإطارات:**

```cpp
// أضف هذه المتغيرات
uint32_t frameCount = 0;
uint32_t lastFrameCount = 0;
unsigned long lastPrintTime = 0;

void loop() {
  // ... كود الاستقبال العادي ...
  
  if (bufferIndex >= expectedSize) {
    executeCommand(expectedSize);
    frameCount++;  // ← أضف هذا
    syncFound = false;
  }
  
  // اطبع عدد الإطارات كل ثانية
  if (millis() - lastPrintTime > 1000) {
    Serial.print("Frames/sec: ");
    Serial.println(frameCount - lastFrameCount);
    lastFrameCount = frameCount;
    lastPrintTime = millis();
  }
}
```

**ج) LED Test (بدون Serial.print):**

```cpp
// أضف LED test على pin 13
const int LED_PIN = 13;

  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);
}

void loop() {
  if (Serial.available() > 0) {
    uint8_t incoming = Serial.read();
    
    if (incoming == 0xAA) {

      digitalWrite(LED_PIN, HIGH);
      delay(50);
      digitalWrite(LED_PIN, LOW);
    }
    
    // ... باقي الكود ...
  }
}
```

##### 📊 النتائج المتوقعة

| إذا ظهر | النتيجة |
|---------|---------|
| `Frames/sec: 50+` | ✅ Arduino يستقبل بشكل طبيعي |
| `Frames/sec: 0` | ❌ لا يصل شيء |
| `Frames/sec: 1-5` | ⚠️ استقبال ضعيف |
| LED يومض | ✅ البيانات تصل |
| LED لا يومض | ❌ البيانات لا تصل |

##### 🔧 كيف تعرف إذا كانت المشكلة من Arduino؟

```
1. تحقق من Serial:
   - Serial.begin(115200) في setup()؟
   - Pins صحيحة (0, 1)؟

2. تحقق من البروتوكول:
   - هل Arduino يبحث عن 0xAA 0x55؟
   - هل bufferIndex يعمل؟

3. تحقق من السرعة:
   - هل Arduino سريع كفاية؟
   - لا تستخدم Serial.print في loop()
```

### المرحلة 4: اختبار Arduino → ESCs

#### 🔍 السؤال: هل Arduino يُرسل PWM إلى ESCs؟

##### ✅ طريقة الاختبار

**أ) استخدام مقياس Pulse Width (Oscilloscope):**

```
1. وصل Oscilloscope بـ Pin 7 (Motor 0)
2. تحقق من الإشارة:
   - يجب أن تكون نبضة بعرض 1000-2000 μs
   - التكرار ~50Hz (كل 20ms)
```

**ب) اختبار بسيط بدون أدوات:**

```cpp
// أضف كود اختبار ESCs

void setup() {
  // ... الكود العادي ...
  
  // اختبار: أرسل 1500μs لكل المحركات
  for (int i = 0; i < 4; i++) {
    esc[i].writeMicroseconds(1500);
  }
  
  // انتظر 3 ثواني
  delay(3000);
  
  // اختبر كل محرك على حدة
  esc[0].writeMicroseconds(1200);  // Motor 0 بطيء
  delay(2000);
  esc[0].writeMicroseconds(1000);  // Motor 0 إيقاف
  
  esc[1].writeMicroseconds(1200);  // Motor 1 بطيء
  delay(2000);
  esc[1].writeMicroseconds(1000);  // Motor 1 إيقاف
}
```

**ج) اختبار القيم الفعلية:**

```cpp
// أضف هذا في executeCommand()

void executeCommand(uint8_t frameSize) {
  uint8_t checksum = 0;
  for (uint8_t i = 0; i < frameSize - 1; i++) {
    checksum ^= buffer[i];
  }
  
  if (checksum == buffer[frameSize - 1]) {
    uint8_t numChannels = buffer[2];
    
    for (uint8_t i = 0; i < NUM_MOTORS && i < numChannels; i++) {
      uint16_t pwm = (buffer[3 + i * 2] << 8) | buffer[3 + i * 2 + 1];
      
      // اطبع القيمة (للاختبار فقط - استخدم LED أو تخزين)
      // لا تستخدم Serial.print هنا لأنه يبطئ النظام
      
      if (pwm < 900) pwm = 900;
      if (pwm > 2100) pwm = 2100;
      
      esc[i].writeMicroseconds(pwm);
    }
    
    // يومض LED عند تطبيق القيم (للاختبار)
    digitalWrite(LED_PIN, HIGH);
    delay(10);
    digitalWrite(LED_PIN, LOW);
  }
}
```

##### 📊 النتائج المتوقعة

| إذا ظهر | النتيجة |
|---------|---------|
| ESC يصدر "بيب" عادي | ✅ الإشارة تصل |
| ESC لا يصدر صوت | ❌ الإشارة لا تصل |
| Oscilloscope يظهر PWM | ✅ Arduino يعمل |
| Oscilloscope خط مستقيم | ❌ Arduino لا يُرسل |
| المحركات تتحرك | ✅ كل شيء يعمل |
| المحركات لا تتحرك | ❌ ESC لا يستقبل |

##### 🔧 كيف تعرف إذا كانت المشكلة من ESC؟

```
1. تحقق من التوصيلات:
   - Signal wire صحيحة؟
   - GND مشترك؟
   - VCC كافي؟

2. تحقق من ESC:
   - هل ESC armed؟
   - هل هناك أخطاء في ESC؟

3. تحقق من الإشارة:
   - PWM ضمن النطاق (1000-2000)؟
   - إشارة مستمرة؟
```

### المرحلة 5: اختبار ESCs → Motors

#### 🔍 السؤال: هل ESCs تتحكم بالمحركات؟

##### ✅ طريقة الاختبار

**أ) اختبار يدوي:**

```
1. فصل المراوح (للسلامة)
2. تشغيل النظام
3. تحريك Joystick للأمام
4. مراقبة ESCs:
   - هل المحركات تدور؟
   - هل السرعات مختلفة؟
5. إعادة تركيب المراوح
```

**ب) اختبار تدريجي:**

```cpp
// كود اختبار ESC → Motor

void testEscMotor() {
  // اختبار كل ESC على حدة
  
  // 1. جميع المحركات إيقاف
  for (int i = 0; i < 4; i++) {
    esc[i].writeMicroseconds(1000);
  }
  delay(1000);
  
  // 2. Motor 0 فقط
  esc[0].writeMicroseconds(1200);
  delay(2000);
  esc[0].writeMicroseconds(1000);
  delay(500);
  
  // 3. Motor 1 فقط
  esc[1].writeMicroseconds(1200);
  delay(2000);
  esc[1].writeMicroseconds(1000);
  delay(500);
  
  // ... وهكذا لكل المحركات
}
```

##### 📊 النتائج المتوقعة

| إذا ظهر | النتيجة |
|---------|---------|
| المحركات تدور بسرعات مختلفة | ✅ كل شيء يعمل |
| المحركات كلها بنفس السرعة | ❌ Mixer لا يعمل |
| بعض المحركات لا تعمل | ❌ ESC أو Motor معطل |
| المحركات لا تدور | ❌ ESC لا يُرسل تيار |
| المحركات تدور عكس الاتجاه | ❌ اتجاه المحرك خطأ |

##### 🔧 كيف تعرف إذا كانت المشكلة من Motor؟

```
1. تحقق من المحرك:
   - هل يدور يدوياً؟
   - هل الأسلاك متصلة؟

2. تحقق من ESC:
   - هل يصدر بيب عادي؟
   - هل LED على ESC يعمل؟

3. تحقق من المراوح:
   - هل المراوح مثبتة بشكل صحيح؟
   - هل الاتجاه صحيح؟
```

// أضف هذا في Android App للاختبار

public class DiagnosticTest {
    
    public static void runFullDiagnostic(Context context) {
        Log.d("DIAG", "=== بدء التشخيص ===");
        
        // 1. اختبار PX4
        testPX4Connection();
        
        // 2. اختبار USB
        testUSBConnection();
        
        // 3. اختبار الإرسال
        testTransmission();
    }
    
    private static void testPX4Connection() {
        Subscription<ActuatorOutputs> sub = 
            new Subscription<>(ActuatorOutputs.class);
        
        ActuatorOutputs outputs = sub.take();
        
        if (outputs != null && outputs.noutputs > 0) {
            Log.d("DIAG", "✅ PX4 يعمل");
            Log.d("DIAG", "   noutputs=" + outputs.noutputs);
            Log.d("DIAG", "   pwm[0]=" + outputs.pwm[0]);
        } else {
            Log.e("DIAG", "❌ PX4 لا يعمل");
        }
    }
    
    private static void testUSBConnection() {
        UsbDevice device = getUsbDevice();
        
        if (device != null) {
            Log.d("DIAG", "✅ USB Device موجود");
            Log.d("DIAG", "   Device: " + device.getDeviceName());
        } else {
            Log.e("DIAG", "❌ USB Device غير موجود");
        }
    }
    
    private static void testTransmission() {
        byte[] testFrame = new byte[]{
            (byte) 0xAA, (byte) 0x55, (byte) 0x04,
            (byte) 0x05, (byte) 0xDC,  // 1500
            (byte) 0x05, (byte) 0xDC,
            (byte) 0x05, (byte) 0xDC,
            (byte) 0x05, (byte) 0xDC,
            (byte) 0x00  // Checksum
        };
        
        int bytesSent = usbSerial.write(testFrame);
        
        if (bytesSent == 12) {
            Log.d("DIAG", "✅ الإرسال نجح: " + bytesSent + " بايت");
        } else {
            Log.e("DIAG", "❌ الإرسال فشل: " + bytesSent + " بايت");
        }
    }
}

### كود Arduino للاختبار

```cpp
// كود تشخيص شامل لـ Arduino

const int LED_PIN = 13;
uint32_t frameCount = 0;
uint32_t errorCount = 0;
unsigned long lastCheck = 0;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  
  // LED يومض 3 مرات عند البدء
  for (int i = 0; i < 3; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(200);
    digitalWrite(LED_PIN, LOW);
    delay(200);
  }
  
  // تهيئة المحركات
  for (int i = 0; i < NUM_MOTORS; i++) {
    esc[i].attach(MOTOR_PINS[i], 900, 2100);
    esc[i].writeMicroseconds(1000);
  }
  
  delay(1500);
}

void loop() {
  // استقبال البيانات
  while (Serial.available() > 0) {
    uint8_t incoming = Serial.read();
    
    if (!syncFound) {
      if (incoming == 0xAA) {
        syncFound = true;
        bufferIndex = 0;
        buffer[0] = incoming;
      }
    } else {
      buffer[++bufferIndex] = incoming;
      
      if (bufferIndex >= 2) {
        uint8_t numChannels = buffer[2];
        uint8_t expectedSize = 2 + 1 + (numChannels * 2) + 1;
        
        if (bufferIndex >= expectedSize) {
          executeCommand(expectedSize);
          frameCount++;
          syncFound = false;
        }
      }
    }
  }
  
  // تشخيص كل ثانية
  if (millis() - lastCheck > 1000) {
    runDiagnostic();
    lastCheck = millis();
  }
}

void runDiagnostic() {
  // يومض LED إذا كان يستقبل
  if (frameCount > 0) {
    digitalWrite(LED_PIN, HIGH);
    delay(50);
    digitalWrite(LED_PIN, LOW);
  }
  
  // يمكنك إضافة Serial.print هنا للتصحيح (لكن احذفه في النهاية)
}

void executeCommand(uint8_t frameSize) {
  uint8_t checksum = 0;
  for (uint8_t i = 0; i < frameSize - 1; i++) {
    checksum ^= buffer[i];
  }
  
  if (checksum == buffer[frameSize - 1]) {
    uint8_t numChannels = buffer[2];
    for (uint8_t i = 0; i < NUM_MOTORS && i < numChannels; i++) {
      uint16_t pwm = (buffer[3 + i * 2] << 8) | buffer[3 + i * 2 + 1];
      
      if (pwm < 900) pwm = 900;
      if (pwm > 2100) pwm = 2100;
      
      esc[i].writeMicroseconds(pwm);
    }
  } else {
    errorCount++;  // إطار خاطئ
  }
}
```

## ⚠️ ملاحظات هامة

1. **لا تستخدم Serial.print في الكود النهائي** - يبطئ النظام.

2. **اختبر كل مرحلة على حدة** - لا تنتقل للمرحلة التالية حتى تتأكد من السابقة.

3. **ابدأ بدون مراوح** - للسلامة، اختبر المحركات بدون مراوح أولاً.

4. **استخدم LED للتشخيص** - يومض عند كل مرحلة لتأكيد عملها.
