# اختبار المحركات من محطة QGC

---

## المشكلة التي حُلَّت

عند الضغط على أي محرك في QGC → Motors Config كانت تظهر رسالة:
```
MAV_CMD_DO_MOTOR_TEST command not supported
```

### السبب:
QGC يرسل الأمر القديم `MAV_CMD_DO_MOTOR_TEST` (رقم 209)  
لكن Commander في PX4 كان يعالج فقط `VEHICLE_CMD_ACTUATOR_TEST` (رقم 310)  
فيسقط الأمر 209 في `default` → يرد بـ UNSUPPORTED

---

### الملف 3: `Commander.cpp` — تنفيذ الدالة

```cpp
unsigned Commander::handleCommandMotorTest(const vehicle_command_s &cmd)
{
    // MAV_CMD_DO_MOTOR_TEST (209) — legacy QGC command
    // param1: motor instance (1-based)
    // param2: throttle type (0=percentage 0-100, 1=PWM 1000-2000)
    // param3: throttle value
    // param4: timeout (seconds)

    if (isArmed() || (_safety.isButtonAvailable() && !_safety.isSafetyOff())) {
        return vehicle_command_ack_s::VEHICLE_CMD_RESULT_DENIED;
    }

    if (_param_com_mot_test_en.get() != 1) {
        return vehicle_command_ack_s::VEHICLE_CMD_RESULT_DENIED;
    }

    const int motor_instance = (int)(cmd.param1 + 0.5f); // 1-based
    if (motor_instance < 1 || motor_instance > actuator_test_s::MAX_NUM_MOTORS) {
        return vehicle_command_ack_s::VEHICLE_CMD_RESULT_UNSUPPORTED;
    }

    // تحويل throttle إلى 0..1
    float value = 0.f;
    const int throttle_type = (int)(cmd.param2 + 0.5f);
    if (throttle_type == 1) {
        value = (cmd.param3 - 1000.f) / 1000.f;  // PWM 1000-2000 → 0-1
    } else {
        value = cmd.param3 / 100.f;               // Percentage 0-100 → 0-1
    }
    value = math::constrain(value, 0.f, 1.f);

    actuator_test_s actuator_test{};
    actuator_test.timestamp   = hrt_absolute_time();
    actuator_test.function    = actuator_test_s::FUNCTION_MOTOR1 + (motor_instance - 1);
    actuator_test.value       = value;
    int timeout_ms            = (int)(cmd.param4 * 1000.f + 0.5f);

    if (timeout_ms <= 0) {
        actuator_test.action = actuator_test_s::ACTION_RELEASE_CONTROL;
    } else {
        actuator_test.action     = actuator_test_s::ACTION_DO_CONTROL;
        actuator_test.timeout_ms = (timeout_ms > 3000) ? 3000 : timeout_ms;
    }

    _actuator_test_pub.publish(actuator_test);
    return vehicle_command_ack_s::VEHICLE_CMD_RESULT_ACCEPTED;
}
```

## مسار البيانات الكامل بعد التعديل

```
QGC (Motors Config)
    ↓ MAV_CMD_DO_MOTOR_TEST (209)
    ↓ param1=محرك, param2=نوع, param3=قيمة, param4=مهلة

Commander.handleCommandMotorTest()
    ↓ تحويل القيمة إلى 0..1
    ↓ بناء actuator_test_s

uORB topic: actuator_test
    ↓

arduino_output.cpp (كان جاهزاً مسبقاً)
    ↓ يقرأ actuator_test
    ↓ يحسب PWM: value → 1000+(value×1000)

Arduino (عبر USB bulkTransfer)
    ↓ PWM signal

ESC → محرك ✅
```

## شروط الأمان

الدالة ترفض الأمر في حالتين:
| الحالة | الرد |
|:---|:---|
| الطائرة مُسلَّحة (Armed) | `VEHICLE_CMD_RESULT_DENIED` |
| المعامل `COM_MOT_TEST_EN ≠ 1` | `VEHICLE_CMD_RESULT_DENIED` |

---

## طريقة الاستخدام من QGC

1. افتح: **Vehicle Setup → Motors**
2. خلع المراوح من جميع المحركات
3. فعّل المفتاح ← يتحول الى `Careful : Motors are enabled`
4. حرّك شريط Throttle إلى **10%**
5. اضغط على **1** أو **2** أو **3** أو **4**
6. راقب المحرك يدور

## مراقبة من logcat

```bash
adb logcat | grep -E "Test motor|MOTORS:|arduino_output"
```

### مثال ناتج ناجح عند الضغط على محرك 1 بـ 10%:
```
Test motor 1 = 0.10
MOTORS: [0.10 nan nan nan] PWM: [1100 1000 1000 1000] USB:OK
```

### تفسير PWM:
| PWM | النسبة |
|:---:|:---:|
| 1000 | 0% (متوقف) |
| 1100 | 10% |
| 1500 | 50% |
| 2000 | 100% |

## ترتيب المحركات في Quad X (4001)

```
        أمام

  3(FL)      1(FR)
    ↖            ↗
          ✈
    ↙            ↘
  2(BL)      4(BR)

        خلف
```

|:---:|:---|:---|:---|
| 1 | Motor 1 | أمام يمين (FR) | CCW ↺ |
| 2 | Motor 2 | خلف يسار (BL) | CCW ↺ |
| 3 | Motor 3 | أمام يسار (FL) | CW ↻ |
| 4 | Motor 4 | خلف يمين (BR) | CW ↻ |
